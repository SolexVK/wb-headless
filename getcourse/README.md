# GetCourse Downloader

Скачивает **все видео уроков** из курса на GetCourse в папки, повторяющие
структуру сайта (блоки → уроки), и сшивает каждое видео в один **MP4 без
«иканья»** на стыках сегментов (ремукс через ffmpeg, без перекодирования —
качество 1:1 с оригиналом).

Работает с любым курсом: достаточно указать стартовую страницу курса — скрипт
сам обойдёт все блоки/модули и уроки, включая случаи с несколькими видео в одном
уроке.

## Как это устроено

1. **Логин** в аккаунт GetCourse через headless-браузер (Playwright/Chromium).
2. **Обход структуры**: со стартовой страницы находятся все блоки курса и уроки в
   них (в правильном порядке).
3. **Извлечение видео**: на странице урока плеер VideoHosting запрашивает
   подписанный HLS-плейлист (`/api/playlist/master/...`). Скрипт перехватывает
   эти запросы из сетевого трафика.
4. **Скачивание**: берётся максимальное доступное качество, сегменты качаются
   параллельно через `curl`, затем `ffmpeg` сшивает их в единый MP4 с непрерывной
   шкалой времени (`-c copy`, без перекодирования).

Ссылки на плейлисты самоподписаны токенами (jwt/plck) с ограниченным сроком
жизни, поэтому извлечение и скачивание идут последовательно по каждому уроку.

## Требования

- **Node.js** ≥ 18
- **ffmpeg** (для сшивки)
- **curl** (есть в macOS и Linux по умолчанию)

## Развёртывание на Mac Mini (через Терминал)

### Шаг 1. Сначала — проверка машины (ничего не меняет)

Прежде чем ставить сервис, посмотрите, какие порты/адреса/процессы уже заняты,
чтобы не задеть другие проекты:

```bash
cd wb-headless/getcourse
bash scripts/inspect-macmini.sh
```

Скрипт покажет слушающие порты (`lsof`), занят ли наш порт **7837**, порт 8080
соседнего проекта, запущенные node-процессы, LaunchAgents, версию Tailscale,
Homebrew/Node/ffmpeg и свободное место на диске. Отдельные полезные команды:

```bash
lsof -nP -iTCP -sTCP:LISTEN        # все слушающие порты и процессы
lsof -nP -iTCP:7837 -sTCP:LISTEN   # занят ли именно наш порт
ps aux | grep -i node | grep -v grep
tailscale version                  # версия Tailscale (CLI)
tailscale status                   # ноды и состояние
df -h /                            # свободное место (важно для спула)
```

### Шаг 2. Развёртывание в изолированное окружение

Скрипт создаёт **изолированное окружение (nvm + отдельный Node LTS)**, входит в
него и уже там ставит зависимости — системный Node и другие проекты не
затрагиваются:

```bash
git clone <адрес-репозитория> wb-headless
cd wb-headless/getcourse
bash scripts/deploy-macmini.sh     # ставит brew/ffmpeg/tailscale, nvm+Node, npm i, Chromium
cp .env.example .env               # затем впишите GCUI_ADMIN_PASS и лимиты
```

Дальше каждый раз перед запуском входите в окружение:

```bash
cd wb-headless/getcourse
export NVM_DIR="$HOME/.nvm" && . "$NVM_DIR/nvm.sh"
nvm use            # активирует Node из .nvmrc
npm run web        # http://127.0.0.1:7837
```

> Для работы только из командной строки (CLI, без веб-интерфейса) дополнительно
> задайте `GC_EMAIL`, `GC_PASSWORD`, `GC_START_URL` в `.env`. Для веб-интерфейса
> эти переменные не нужны — логин/ссылка/папка вводятся в браузере.

## Запуск

Предпросмотр структуры курса (ничего не качает):

```bash
npm run map
```

Скачать весь курс:

```bash
npm start
# или указать стартовую страницу прямо в команде:
node src/index.mjs "https://ваша-школа.getcourse.ru/teach/control/stream/view/id/000000000"
```

Видео появятся в папке `output/` (задаётся в `GC_OUTPUT`):

```
output/
  01 Название блока/
    01 Название урока.mp4
    02 Название урока.mp4
  02 Название блока/
    01 Название урока.mp4
  course_map.json         # карта курса
  download_report.json    # отчёт: что скачано / пропущено / с ошибками
```

Повторный запуск **продолжает с места остановки**: уже скачанные `*.mp4`
пропускаются. Это удобно при обрыве связи или для докачки новых уроков.

## Настройки (.env)

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `GC_EMAIL` | Логин GetCourse | — (обязательно) |
| `GC_PASSWORD` | Пароль | — (обязательно) |
| `GC_START_URL` | Стартовая страница курса | — (обязательно) |
| `GC_OUTPUT` | Куда сохранять | `./output` |
| `GC_CONCURRENCY` | Параллельных загрузок сегментов | `10` |
| `GC_LIMIT` | Ограничить число уроков (для теста) | `0` (все) |
| `FFMPEG` | Путь к ffmpeg, если не в PATH | `ffmpeg` |
| `CHROMIUM_PATH` | Свой бинарник Chromium | (управляется Playwright) |
| `GC_HEADFUL` | Показать окно браузера (отладка) | выкл. |
| `GC_NO_TLS_WORKAROUND` | Отключить обход TLS1.2/HTTP1.1 | выкл. |

## Веб-интерфейс

Кроме командной строки есть веб-интерфейс: вход по аккаунту, выбор папки,
запуск и живой прогресс скачивания в браузере.

```bash
cp .env.example .env      # задайте как минимум GCUI_ADMIN_USER / GCUI_ADMIN_PASS
npm run web               # поднимает http://127.0.0.1:7837
```

При первом запуске создаётся администратор (логин/пароль из `.env`,
`GCUI_ADMIN_USER` / `GCUI_ADMIN_PASS`).

### Два режима хранения (важно)

Роль аккаунта определяет, куда попадают видео:

- **Владелец / админ (`localAccess`)** — видит структуру папок Mac Mini и
  сохраняет курсы прямо на диск. В форме есть выбор папки («Обзор…», ограничен
  `GCUI_BROWSE_ROOT`).
- **Подписчик (обычный аккаунт)** — **не видит** файловую систему сервера (это
  небезопасно). Его видео скачиваются во **временный персональный спул** на Mac
  Mini; в интерфейсе он видит прогресс, а по готовности жмёт **«Скачать»** и
  забирает файл к себе на компьютер. Обзор папок сервера для него запрещён (403).

### Лимиты и автоочистка (для подписчиков)

- **Дневной объём**: по умолчанию `GCUI_DAILY_GB=200` ГБ на пользователя в день
  (плюс необязательный лимит по числу файлов `GCUI_DAILY_FILES`). При исчерпании
  задача останавливается со статусом «лимит дня». Счётчик виден в интерфейсе.
- **Автоудаление**: файлы в спуле удаляются через `GCUI_RETENTION_MIN=30` минут
  после скачивания/создания — пользователь предупреждён в интерфейсе. Отсчёт
  перезапускается при каждом скачивании файла.
- **Квота на диск**: суммарный размер спула пользователя не превышает
  `GCUI_USER_QUOTA_GB` (по умолчанию 200 ГБ) — «уборщик» удаляет самые старые
  файлы. Фоновая очистка идёт каждые 5 минут.

### Подписка и оплата

Запуск скачивания доступен только при активной подписке.

- **Ключи доступа** (работает сейчас): пользователь вводит ключ из
  `GCUI_LICENSE_KEYS`, подписка активируется на `GCUI_LICENSE_DAYS` дней. Админ
  может включать/выключать подписку вручную.
- **ЮKassa** (реализована, но по умолчанию **заглушена**): кнопка «Оплата картой»
  показывается как «скоро». Включается позже без правок кода — задать
  `GCUI_YOOKASSA_ENABLED=1` и реквизиты магазина; вебхук
  `/api/billing/yookassa/webhook` активирует подписку после оплаты.

### Порты и отсутствие конфликтов

Сервер слушает **127.0.0.1:7837** (соседний проект на этом Mac занимает 8080 —
пересечения нет; проверьте `scripts/inspect-macmini.sh`). Порт/адрес меняются
через `GCUI_PORT` / `GCUI_HOST`.

### Внешний доступ через Tailscale (публичный Funnel)

Если на машине уже есть Funnel на `:443` (у другого проекта), трогать его
нельзя. Поэтому по умолчанию скрипт вешает наш сервис на **порт 8443** того же
узла (Funnel разрешает 443/8443/10000) — **аддитивно, существующий 443 не
затрагивается**:

```bash
./scripts/tailscale-serve.sh
```

Адрес получится вида `https://<имя-мака>.<tailnet>.ts.net:8443` — это понятное
имя узла, а не IP. Снять только наш маршрут (не трогая 443):
`tailscale serve --https=8443 off`.

Приватный доступ (только свой tailnet, без публикации): `PRIVATE=1 ./scripts/tailscale-serve.sh`.

Отдельное «красивое» имя `https://getcourse.<tailnet>.ts.net` возможно через
выделенный узел: `MODE=node TS_HOSTNAME=getcourse ./scripts/tailscale-serve.sh`
(нужен бинарь `tailscaled` и включённый атрибут `funnel` для узла в ACL тейлнета).

Проверить Tailscale заранее: `tailscale version`, `tailscale status`,
`tailscale serve status`.

### Автозапуск на Mac Mini (LaunchAgent)

```bash
cp scripts/com.getcourse.downloader.plist.example \
   ~/Library/LaunchAgents/com.getcourse.downloader.plist
# отредактируйте пути и GCUI_ADMIN_PASS внутри, затем:
launchctl load ~/Library/LaunchAgents/com.getcourse.downloader.plist
```

### Безопасность

- Пароли аккаунтов интерфейса хранятся как scrypt-хэши; сессии — httpOnly-cookie.
- Открытой регистрации нет: аккаунты заводит администратор.
- Файловую систему сервера видит **только владелец/админ** (`localAccess`), и то
  в пределах `GCUI_BROWSE_ROOT`. Подписчики к ФС доступа не имеют — только
  временный персональный спул и скачивание своих файлов.
- Пароль GetCourse не сохраняется — живёт только на время запуска задачи.
- При публичном доступе (Funnel) обязательно смените пароль администратора,
  используйте стойкие пароли и отдельные ключи доступа на каждого клиента —
  интерфейс становится доступен из интернета.

## Заметки

- **Качество**: берётся максимальное из предложенных плеером (обычно до 720p —
  зависит от того, что загрузил автор курса).
- **Антибот CDN**: по умолчанию включён обход (TLS 1.2 + HTTP/1.1), т.к. edge
  GetCourse сбрасывает соединение «слишком новому» TLS-фингерпринту headless-
  браузера. На обычном подключении это не мешает; при желании отключается через
  `GC_NO_TLS_WORKAROUND=1`.
- **Только для личного использования** приобретённого вами курса. При публичной
  раздаче доступа учитывайте условия использования GetCourse и авторские права
  на материалы курсов.
