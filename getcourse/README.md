# GetCourse Downloader

Скачивает **все видео уроков** из курса на GetCourse в папки, повторяющие
структуру сайта (блоки → уроки), и сшивает каждое видео в один **MP4 без
«иканья»** на стыках сегментов (ремукс через ffmpeg, без перекодирования —
качество 1:1 с оригиналом).

Работает с любым курсом: достаточно указать стартовую страницу курса — скрипт
сам обойдёт все блоки/модули и уроки, включая случаи с несколькими видео в одном
уроке.

## Как это устроено

1. **Логин** в аккаунт GetCourse через headless-браузер (Playwright/Chromium).
2. **Обход структуры**: со стартовой страницы находятся все блоки курса и уроки в
   них (в правильном порядке).
3. **Извлечение видео**: на странице урока плеер VideoHosting запрашивает
   подписанный HLS-плейлист (`/api/playlist/master/...`). Скрипт перехватывает
   эти запросы из сетевого трафика.
4. **Скачивание**: берётся максимальное доступное качество, сегменты качаются
   параллельно через `curl`, затем `ffmpeg` сшивает их в единый MP4 с непрерывной
   шкалой времени (`-c copy`, без перекодирования).

Ссылки на плейлисты самоподписаны токенами (jwt/plck) с ограниченным сроком
жизни, поэтому извлечение и скачивание идут последовательно по каждому уроку.

## Требования

- **Node.js** ≥ 18
- **ffmpeg** (для сшивки)
- **curl** (есть в macOS и Linux по умолчанию)

## Установка на Mac Mini (через Терминал)

```bash
# 1. Установить Homebrew, если ещё нет:
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 2. Установить Node.js и ffmpeg:
brew install node ffmpeg

# 3. Получить проект (клонировать репозиторий) и перейти в папку:
git clone <адрес-репозитория> wb-headless
cd wb-headless/getcourse

# 4. Установить зависимости (заодно скачается Chromium для Playwright):
npm install

# 5. Настроить доступ:
cp .env.example .env
# открыть .env в редакторе и вписать GC_EMAIL, GC_PASSWORD, GC_START_URL
nano .env
```

## Запуск

Предпросмотр структуры курса (ничего не качает):

```bash
npm run map
```

Скачать весь курс:

```bash
npm start
# или указать стартовую страницу прямо в команде:
node src/index.mjs "https://ваша-школа.getcourse.ru/teach/control/stream/view/id/000000000"
```

Видео появятся в папке `output/` (задаётся в `GC_OUTPUT`):

```
output/
  01 Название блока/
    01 Название урока.mp4
    02 Название урока.mp4
  02 Название блока/
    01 Название урока.mp4
  course_map.json         # карта курса
  download_report.json    # отчёт: что скачано / пропущено / с ошибками
```

Повторный запуск **продолжает с места остановки**: уже скачанные `*.mp4`
пропускаются. Это удобно при обрыве связи или для докачки новых уроков.

## Настройки (.env)

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `GC_EMAIL` | Логин GetCourse | — (обязательно) |
| `GC_PASSWORD` | Пароль | — (обязательно) |
| `GC_START_URL` | Стартовая страница курса | — (обязательно) |
| `GC_OUTPUT` | Куда сохранять | `./output` |
| `GC_CONCURRENCY` | Параллельных загрузок сегментов | `10` |
| `GC_LIMIT` | Ограничить число уроков (для теста) | `0` (все) |
| `FFMPEG` | Путь к ffmpeg, если не в PATH | `ffmpeg` |
| `CHROMIUM_PATH` | Свой бинарник Chromium | (управляется Playwright) |
| `GC_HEADFUL` | Показать окно браузера (отладка) | выкл. |
| `GC_NO_TLS_WORKAROUND` | Отключить обход TLS1.2/HTTP1.1 | выкл. |

## Веб-интерфейс

Кроме командной строки есть веб-интерфейс: вход по аккаунту, выбор папки,
запуск и живой прогресс скачивания в браузере.

```bash
cp .env.example .env      # задайте как минимум GCUI_ADMIN_USER / GCUI_ADMIN_PASS
npm run web               # поднимает http://127.0.0.1:7837
```

При первом запуске создаётся администратор (логин/пароль из `.env`,
`GCUI_ADMIN_USER` / `GCUI_ADMIN_PASS`). Возможности:

- **Скачивание**: вводите email/пароль GetCourse, ссылку на курс и выбираете
  папку (кнопка «Обзор…» — серверный обзор папок, ограничен `GCUI_BROWSE_ROOT`).
  Пароль GetCourse нигде не сохраняется — используется только для запуска.
- **Задачи**: список запусков с прогресс-баром, счётчиком сегментов и логом
  (через Server-Sent Events). Можно отменить.
- **Пользователи** (для админа): создать аккаунт, включить/выключить подписку,
  удалить.
- **Подписка**: запуск скачивания доступен только при активной подписке.
  Пользователь активирует её ключом (`GCUI_LICENSE_KEYS`), админ — вручную. Под
  реальную оплату (Stripe / ЮKassa) архитектура готова: платёжный вебхук должен
  выставлять `subscription.active` у пользователя (точка расширения —
  `web/server.mjs`, роут `/api/billing`).

### Порты и отсутствие конфликтов

Сервер слушает **127.0.0.1:7837** (другой проект на этом Mac занимает 8080 —
пересечения нет). Порт/адрес меняются через `GCUI_PORT` / `GCUI_HOST`.

### Внешний доступ через Tailscale (с понятным именем)

```bash
# приватно (только ваш tailnet), даёт https://getcourse.<tailnet>.ts.net
./scripts/tailscale-serve.sh

# публично в интернет (для платящих клиентов):
PUBLIC=1 ./scripts/tailscale-serve.sh
```

Скрипт поднимает **отдельный узел Tailscale** с именем `getcourse` (меняется
через `TS_HOSTNAME`), поэтому адрес — понятное имя, а не IP, и он не конфликтует
с другими проектами и их `:443` на этой машине. Требуется CLI-версия Tailscale
(`brew install tailscale`); для варианта из Mac App Store в скрипте есть заметка.

### Автозапуск на Mac Mini (LaunchAgent)

```bash
cp scripts/com.getcourse.downloader.plist.example \
   ~/Library/LaunchAgents/com.getcourse.downloader.plist
# отредактируйте пути и GCUI_ADMIN_PASS внутри, затем:
launchctl load ~/Library/LaunchAgents/com.getcourse.downloader.plist
```

### Безопасность

- Пароли аккаунтов интерфейса хранятся как scrypt-хэши; сессии — httpOnly-cookie.
- Открытой регистрации нет: аккаунты заводит администратор.
- Обзор файловой системы жёстко ограничен папкой `GCUI_BROWSE_ROOT`.
- При публичном доступе (Funnel) обязательно смените пароль администратора и
  используйте стойкие пароли — интерфейс станет доступен из интернета.

## Заметки

- **Качество**: берётся максимальное из предложенных плеером (обычно до 720p —
  зависит от того, что загрузил автор курса).
- **Антибот CDN**: по умолчанию включён обход (TLS 1.2 + HTTP/1.1), т.к. edge
  GetCourse сбрасывает соединение «слишком новому» TLS-фингерпринту headless-
  браузера. На обычном подключении это не мешает; при желании отключается через
  `GC_NO_TLS_WORKAROUND=1`.
- **Только для личного использования** приобретённого вами курса. При публичной
  раздаче доступа учитывайте условия использования GetCourse и авторские права
  на материалы курсов.
