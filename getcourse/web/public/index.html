Новое скачивание

Откройте нужный курс на GetCourse так, чтобы был виден список уроков, и скопируйте адрес из строки браузера — он должен содержать /stream/view/id/ЧИСЛО. Можно и адрес отдельного урока (/lesson/view/id/ЧИСЛО). Ссылка на общий список курсов (/teach/control/stream) не подойдёт.

Видео скачивается во временное хранилище и затем передаётся вам. Файлы удаляются автоматически через 30 мин — успевайте сохранить. Дневной лимит: 200 ГБ.
Ваш браузер не поддерживает выбор папки — готовые видео можно будет скачать кнопкой во вкладке «Задачи» (обычно в папку «Загрузки»).
Дополнительно

Пароль GetCourse используется только для этого запуска и не сохраняется на сервере. Качество берётся максимальное из доступных, видео склеивается в MP4 без «иканья».
