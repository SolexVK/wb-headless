# Video Splitter + LLM Transcriber

Мини-приложение для **Windows 10**: разрезает длинные видео на куски заданного
размера (300 / 500 / 1000 МБ или свой) и умеет транскрибировать их через
подключаемый LLM (любой OpenAI-совместимый Whisper API).

- **Нарезка без перекодирования** (stream copy) — быстро, без потери качества.
- **Транскрибация** — извлекает аудио, режет на фрагменты под лимит API,
  распознаёт речь и сохраняет `.txt` и субтитры `.srt` рядом с файлом.
- Простой графический интерфейс (Tkinter), одна внешняя зависимость (`requests`).

---

## Что нужно установить

1. **Python 3.10+** — https://www.python.org/downloads/
   При установке отметьте галочку **«Add Python to PATH»**.
2. **ffmpeg** (и ffprobe) — нужен для нарезки и извлечения аудио. Варианты:
   - установить в систему и добавить в `PATH`
     (напр. пакет с https://www.gyan.dev/ffmpeg/builds/), **или**
   - положить `ffmpeg.exe` и `ffprobe.exe` в папку `ffmpeg\bin` рядом с
     программой, **или**
   - указать путь к `ffmpeg.exe` во вкладке «Настройки LLM».

## Запуск из исходников

Дважды кликните **`run.bat`** — он поставит зависимости и запустит приложение.
Или вручную:

```bat
pip install -r requirements.txt
python main.py
```

## Сборка одного .exe (без Python на целевой машине)

Дважды кликните **`build_exe.bat`**. Готовый файл появится в
`dist\VideoSplitter.exe`. ffmpeg в exe не встраивается — положите `ffmpeg\bin`
рядом с exe или установите его в `PATH`.

## Как пользоваться

### Нарезка

1. Вкладка **«Нарезка»** → выберите видео и папку для кусков.
2. Выберите размер куска (300 / 500 / 1000 МБ или введите свой).
3. **«Разрезать видео»**. Куски: `имя_part000.mp4`, `имя_part001.mp4`, …

> Размер каждого куска — *приблизительный*. Копирование потока режет только по
> ключевым кадрам, поэтому реальный размер обычно отличается на ±10-15 %.

### Транскрибация

1. Вкладка **«Настройки LLM»** → укажите эндпоинт, API-ключ, модель, язык.
   Ключ хранится **локально** в `%APPDATA%\VideoSplitter\config.json`.
2. Вкладка **«Транскрибация»** → добавьте файлы (можно куски после нарезки).
3. **«Транскрибировать»**. Рядом с каждым файлом появятся `.txt` и `.srt`.

#### Примеры настроек LLM

| Провайдер | Base URL | Модель |
|-----------|----------|--------|
| OpenAI | `https://api.openai.com/v1` | `whisper-1` или `gpt-4o-transcribe` |
| Groq | `https://api.groq.com/openai/v1` | `whisper-large-v3` |
| Локальный (whisper.cpp / faster-whisper server) | `http://localhost:8000/v1` | зависит от сервера |

Подходит любой сервер, реализующий эндпоинт
`POST {base_url}/audio/transcriptions` в формате OpenAI.

## Структура проекта

```
video-splitter/
├─ main.py                     точка входа
├─ run.bat                     запуск из исходников
├─ build_exe.bat              сборка автономного .exe
├─ requirements.txt
└─ video_splitter/
   ├─ app.py                  графический интерфейс (Tkinter)
   ├─ config.py               настройки (JSON в папке пользователя)
   ├─ ffmpeg_utils.py         поиск ffmpeg/ffprobe, probe
   ├─ splitter.py             нарезка по размеру
   └─ transcriber.py          транскрибация через LLM API
```

## Частые вопросы

- **«ffmpeg не найден»** — установите ffmpeg (см. выше) или укажите путь в
  настройках.
- **Кусок больше/меньше цели** — это нормально при нарезке без перекодирования
  (режется по ключевым кадрам). Для точного размера потребовалось бы
  перекодирование (медленно и с потерей качества).
- **API вернул 401/403** — проверьте API-ключ и base URL.
- **Файл слишком большой для API** — приложение само режет аудио на фрагменты
  (по умолчанию по 600 сек); при необходимости уменьшите значение в
  `config.json` (`audio_chunk_seconds`).
