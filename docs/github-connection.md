# Подключение к GitHub (Claude Code on the web)

Подробная пошаговая инструкция: как связать репозиторий с Claude Code и
работать с ним так, как мы это делаем в этом проекте.

## Как всё устроено

Claude Code on the web запускает сессию в **изолированном облачном окружении**.
При старте сессии репозиторий клонируется заново, Claude работает на отдельной
ветке, коммитит и пушит изменения обратно в GitHub. Доступ к репозиториям даёт
**GitHub-приложение Claude**, которое нужно один раз установить в аккаунт или
организацию.

Схема: `Ваш GitHub` → (устанавливаете GitHub App Claude) → `Claude Code`
клонирует репо в облаке → работает на ветке → пушит обратно → (по запросу) PR.

---

## Шаг 1. Войдите в Claude Code в вебе

1. Откройте [claude.ai/code](https://claude.ai/code) (или раздел **Code** в
   приложении Claude).
2. Войдите под своим аккаунтом Claude (тот же логин, что и на claude.ai).
3. Если это первый запуск — вы увидите экран с предложением подключить
   источник кода (GitHub).

## Шаг 2. Запустите подключение GitHub

1. Нажмите **Connect GitHub** (или *Add repository* / *Connect a repository*).
2. Откроется окно авторизации GitHub — подтвердите вход в свой GitHub-аккаунт,
   если потребуется.
3. GitHub предложит **установить приложение Claude** (*Install Claude* /
   *Configure*).

## Шаг 3. Выберите, куда установить приложение

GitHub спросит, в какой аккаунт установить приложение:

- **Личный аккаунт** — если репозиторий ваш личный (как `SolexVK/wb-headless`).
- **Организация** — если репозиторий принадлежит организации.
  ⚠️ Для организации установку часто должен **одобрить администратор**. Если у
  вас нет прав, GitHub отправит запрос владельцу организации, и подключение
  завершится после его подтверждения.

## Шаг 4. Выдайте доступ к репозиториям

В окне установки выберите объём доступа:

- **All repositories** — приложение видит все текущие и будущие репозитории.
- **Only select repositories** — вручную отметьте нужные (рекомендуется).
  Начните вводить имя, например `wb-headless`, и выберите его в списке.

Нажмите **Install** (или **Save**). После этого GitHub вернёт вас в Claude Code.

> Изменить список репозиториев можно в любой момент: GitHub → *Settings* →
> *Applications* → *Claude* → *Configure*.

## Шаг 5. Создайте сессию: репозиторий + ветка

1. В Claude Code выберите подключённый репозиторий из списка.
2. Укажите **базовую ветку** — обычно `main` (от неё будет создана рабочая
   ветка).
3. Запустите сессию. Облачное окружение автоматически склонирует репозиторий —
   вручную `git clone` делать не нужно.

## Шаг 6. Работайте и пушьте изменения

1. Опишите задачу. Claude создаёт **рабочую ветку** вида
   `claude/<описание>-<id>` (например, `claude/github-connection-guide-7mm935`).
2. Claude вносит изменения, делает коммиты с понятными сообщениями и **пушит**
   их в эту ветку на GitHub.
3. Прямой пуш в защищённые ветки (`main`) **не выполняется** без явного
   разрешения.

## Шаг 7. Откройте Pull Request (по желанию)

1. PR создаётся **только по явной просьбе** — попросите «открой PR».
2. Claude оформит PR против базовой ветки; если в репозитории есть шаблон
   (`.github/pull_request_template.md`), он будет использован.
3. Дальше — обычное код-ревью и merge на стороне GitHub.

## Как проверить, что подключение работает

Выполните в сессии:

```bash
git remote -v      # должен указывать на github.com/<owner>/<repo>
git branch -a      # видны локальная и origin-ветки
git fetch origin   # проходит без ошибок авторизации
git status         # показывает текущую рабочую ветку
```

Если `git fetch` проходит без ошибок авторизации — подключение рабочее.

## Управление доступом и отзыв прав

- **Добавить/убрать репозитории:** GitHub → *Settings* → *Applications* →
  *Claude* → *Configure*.
- **Организация:** администратор управляет доступом в настройках Claude
  (`claude.ai/admin-settings`) и в установке GitHub-приложения организации.
- **Полностью отозвать доступ:** удалите установку GitHub-приложения Claude
  (*Configure* → *Uninstall*).

## Типичные проблемы

| Симптом | Причина и решение |
| --- | --- |
| Репозитория нет в списке | Не добавлен в приложение → *Configure* → добавьте его |
| «Requires approval» | Организация ждёт одобрения администратора |
| Ошибка авторизации при push | Приложение переустановлено/отозвано — переподключите |
| Изменения пропали после сессии | Не были закоммичены и запушены (окружение эфемерное) |

## Полезно помнить

- Окружение **эфемерное**: всё, что не закоммичено и не запушено, теряется при
  завершении сессии.
- Claude пушит **только в свою рабочую ветку**.
- Pull Request создаётся **только по явной просьбе**.
