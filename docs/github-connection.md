# Подключение к GitHub (Claude Code on the web)

Мини-инструкция: как связать репозиторий с Claude Code и работать с ним так,
как мы это делаем в этом проекте.

## Как всё устроено

Claude Code on the web запускает сессию в **изолированном облачном окружении**.
При старте сессии репозиторий клонируется заново, Claude работает на отдельной
ветке, коммитит и пушит изменения обратно в GitHub. Доступ к репозиториям даёт
**GitHub-приложение Claude**, которое нужно один раз установить в аккаунт или
организацию.

## Шаги подключения

1. **Откройте Claude Code в вебе** — [claude.ai/code](https://claude.ai/code)
   (или раздел Code в приложении Claude).

2. **Подключите GitHub.** Нажмите *Connect GitHub* и авторизуйте установку
   GitHub-приложения Claude. Для организации установку должен подтвердить
   администратор.

3. **Дайте доступ к репозиториям.** В окне установки выберите либо *All
   repositories*, либо конкретные репозитории (например, `SolexVK/wb-headless`).
   Список можно изменить позже в настройках приложения на GitHub.

4. **Выберите репозиторий и ветку.** Создавая сессию, укажите репозиторий и
   базовую ветку (обычно `main`). Окружение склонирует его автоматически.

5. **Работайте и пушьте.** Claude создаёт рабочую ветку вида
   `claude/<описание>-<id>`, вносит изменения, коммитит и пушит их. По запросу
   открывает Pull Request против базовой ветки.

## Как проверить, что подключение работает

```bash
git remote -v      # должен указывать на github.com/<owner>/<repo>
git branch -a      # видны локальная и origin-ветки
git fetch origin   # проходит без ошибок авторизации
```

## Управление доступом

- **Репозитории:** GitHub → *Settings* → *Applications* → *Claude* →
  *Configure* — здесь добавляют или убирают репозитории.
- **Организация:** администратор управляет доступом в настройках Claude
  (`claude.ai/admin-settings`) и в установке GitHub-приложения организации.
- **Отзыв доступа:** удалите репозиторий из списка приложения или удалите саму
  установку GitHub-приложения.

## Полезно помнить

- Окружение **эфемерное**: всё, что не закоммичено и не запушено, теряется при
  завершении сессии.
- Claude пушит **только в свою рабочую ветку**; прямой пуш в защищённые ветки
  не выполняется без явного разрешения.
- Pull Request создаётся **только по явной просьбе**.
