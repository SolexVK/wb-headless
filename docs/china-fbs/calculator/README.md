# Юнит-калькулятор WB — Китай (FBS), веб-приложение

Интерактивный калькулятор юнит-экономики трансграничной модели (Китай → РФ, FBS)
по оферте Wildberries. Чистый HTML/CSS/JS, без сборки и зависимостей.

## Запуск
Открыть `index.html` в браузере (двойной клик) — приложение работает офлайн.
`standalone.html` — та же версия одним файлом (CSS/JS встроены), удобно переслать/захостить.

## Структура
| Файл | Назначение |
|---|---|
| `index.html` | Разметка страницы |
| `styles.css` | Оформление (светлая/тёмная тема) |
| `app.js` | Модель затрат + генерация формы + рендер результатов |
| `standalone.html` | Автосборка «всё в одном файле» |

## Как устроена модель
- Все расчёты в **юанях (CNY)** — валюта договора (п. 5.12). Рубль — только для витрины.
- Форма генерируется из массива `FIELDS` в `app.js` — новые поля добавляются одной строкой.
- Ядро расчёта — чистая функция `computeUnit(v)`, её же использует сетка чувствительности.

## Статьи затрат (привязка к оферте)
Комиссия `В = Рц×кВВ` (мин. 1%, п. 12.2) · эквайринг/конвертация сверх комиссии (п. 12.2.1) ·
логистика 8+(Б−1)×2 (п. 13.1.11.1) или весовая (п. 13.1.12) · коэффициент Клх 1…4 / ×25 без
габаритов (п. 13.3) · хранение (п. 13.2) · обратная логистика 1×/2× (п. 13.1.14) ·
утилизация (п. 13.4) · продвижение/ДРР (п. 14) · штрафы (п. 9.9.6) · НДС до 22% (п. 9.2.3).

## Логика возвратов
На 1 выкупленную единицу приходится `1/выкуп` заказов и `(1−выкуп)/выкуп` возвратов:
прямая логистика — на все заказы, обратная — на возвраты (× множитель), часть возвратов
уходит в утиль (теряется себестоимость + тариф утилизации).

## Способы доставки
- **Доставка силами селлера (DBS)** — вы сами доставляете покупателю; WB логистику не берёт.
  Появляется поле «Тариф доставки селлера, $/кг» → на 1 шт = тариф × вес, в себестоимость до ВБ.
- **WB Standard / Plus / Express / Гонконг (FBS)** — кросс-бордер силами WB по официальному
  весовому тарифу (ставка ¥/кг × вес + фикс ¥/заказ), уже включает возврат на ФФ и хранение.
  Поле $/кг при этом скрывается.

## Тарифы и комиссии — в отдельном файле (без правки кода)
Тарифы логистики и комиссии вынесены в **`tariffs.json`** (в git — базовые значения).
Калькулятор читает его при загрузке, а поверх — необязательный **`tariffs.override.json`**
(в `.gitignore`), если он есть. Если fetch недоступен (одиночный `standalone.html`, `file://`,
артефакт) — используется встроенный слепок `EMBEDDED` в `app.js`.

Приоритет: `tariffs.override.json` → `tariffs.json` → `EMBEDDED`.

### Обновление тарифов WB
```
cd docs/china-fbs/tools
python3 update-wb-tariffs.py            # текущий известный URL PDF
python3 update-wb-tariffs.py <URL_PDF>  # если WB опубликовал новый файл тарифа
```
Скрипт скачивает официальный PDF, парсит ставки и пишет **`calculator/tariffs.override.json`**.
Код (`app.js`) не меняется, git-конфликтов нет. Перезапуск сервера не нужен — обновите страницу.
Зависимости: `pdfplumber`, `curl`. Лимиты габаритов зафиксированы в скрипте (меняются редко),
авто-обновляются ставки. Комиссии по категориям правьте в `tariffs.json` → `categories`.

> Комиссии и «Курс ВБ» — ориентир; после регистрации кабинета сверьте по своему аккаунту.
