# Юнит-модель WB — Китай (FBS / трансграница)

Калькулятор: **`wb_china_unit_calc.xlsx`** — 3 листа: `Инструкция`, `Калькулятор`, `Сценарии`.
Все суммы в **юанях (CNY)** — валюта договора (п. 5.12 оферты). Курс используется только для
справочного отображения витрины в рублях.

## Что заполнять
Только ячейки с жёлтой заливкой (синий шрифт) на листе `Калькулятор`. Остальное — формулы.
На листе `Сценарии` можно менять шапки таблиц (доля выкупа, ставка комиссии) — они синие.

## Формула комиссии (п. 12.2)
```
В = Рц × кВВ − И
```
- **Рц** — розничная цена в юанях (с вашими скидками), п. 5.1;
- **кВВ** — коэффициент комиссии из тарифов (п. 6.6); если < 1%, считается 1% (п. 12.2);
- **И** — возмещаемые издержки ВБ.

## Статьи затрат и пункты оферты

| Статья | Как считается | Пункт |
|---|---|---|
| Комиссия ВБ | Рц × кВВ (мин. 1%) | 6.2, 12.2 |
| Эквайринг + конвертация | % от Рц, **сверх** комиссии | 12.2.1 |
| Логистика прямая (РФ) | 8 + (Б−1)×2 CNY, Б — объём в литрах (округл. вверх, мин. 1) | 13.1.11.1 |
| Логистика весовая | Ру = ФВз × ТФВз + Тз (вес округл. до 100 г) | 13.1.12 |
| Логистика из Китая | Тариф из таблицы складов КНР | 13.1.11.2 |
| Коэффициент Клх | Множитель к логистике и хранению: 1 / 1,5 / 2 / 3 / 4 по СоА; нет габаритов → 25 | 13.3 |
| Хранение | Тариф × дней × Клх | 13.2 |
| Возврат (обратная логистика) | 1× (возврат покупателем / не вывезен из КНР) или 2× (не прошёл таможню РФ) | 13.1.14 |
| Утилизация | Тариф за единицу | 13.4 |
| Продвижение (ДРР) | % от выручки (CPM/CPO/CPC) | 14 |
| Штрафы | Лимит по обороту: 5% / 7,5% / 10% и абсолютные потолки | 9.9.6 |
| НДС | Цена включает косвенные налоги; ставка до 22%; неплательщик → 0 | 5.2, 9.2.3, 6.8 |

## Логика возвратов в модели
На 1 **выкупленную** единицу приходится `1/выкуп` заказов и `(1−выкуп)/выкуп` возвратов:
- прямая логистика начисляется на **все** заказы (включая невыкупленные);
- обратная логистика — на возвраты (× множитель 1 или 2);
- часть возвратов уходит в утиль → теряется себестоимость + тариф утилизации.

## Выплаты (влияет на оборотный капитал, не на маржу)
Порог выплаты **10 000 CNY** на 23:59:59 воскресенья; выплата в течение 10 раб. дней с
понедельника; платят только за доставленный товар. Пп. 5.5–5.7.

## Важно
Тарифы ВБ меняются ежедневно и в одностороннем порядке (пп. 6.6, 7.2) — обновляйте
входные ставки перед каждым расчётом. Оферта двуязычна; приоритет — русская версия (п. 2.5).
