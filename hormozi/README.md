# Система Хормози — база знаний + скиллы

Полная дистилляция бизнес-серии Алекса Хормози ($100M) в переиспользуемую **систему скиллов Claude** + база знаний.

## Что где лежит

```
hormozi/
├── README.md               ← этот файл
├── 00-synthesis-map.md     ← карта пересечений 4 книг + диаграмма конвейера
└── books/                  ← разборы книг (глубокая база знаний)
    ├── 01-100m-offers.md         (что продавать — Grand Slam Offer)
    ├── 02-100m-money-models.md   (как заставить купить — воронка офферов)
    ├── 03-100m-leads.md          (кого/как найти — Core Four)
    └── 04-100m-lost.md           (углубление + CFA-математика)

.claude/skills/
├── hormozi/                ← ДИСПЕТЧЕР (точка входа, роутер по задаче)
├── hormozi-offers/         ← Grand Slam Offer: рынок, аватар, Value Equation, усилители
├── hormozi-leads/          ← привлечение: Core Four, лид-магнит, Rule of 100, lead getters
├── hormozi-money-models/   ← последовательности офферов: attraction/upsell/downsell/continuity
└── hormozi-finance/        ← юнит-экономика: CAC/LTGP/PPD/CFA (+ scripts/cfa.py)
```

## Как пользоваться

Просто опиши задачу по-русски — сработает нужный скилл:
- «Помоги собрать оффер / подними цену / кто мой клиент» → `hormozi-offers`
- «Мало клиентов / где брать лидов / сделай лид-магнит» → `hormozi-leads`
- «Какой апселл добавить / окупить рекламу быстрее» → `hormozi-money-models`
- «Посчитай юнит-экономику / сходится ли реклама» → `hormozi-finance`
- «Хочу вырастить бизнес» (широко) → `hormozi` проведёт по roadmap

## Архитектура (кратко)

Конвейер: **Аватар → Offer → Lead Magnet → Leads → Money Model → Finance ↺**
Единая цель системы: **LTGP : CAC ≥ 3 : 1** и **CFA Level 3** (окупаемость привлечения за ≤30 дней).

Формат: билингва (RU-инструкции, EN-термины), примеры универсальные.
Подробности связей — в `00-synthesis-map.md`.
