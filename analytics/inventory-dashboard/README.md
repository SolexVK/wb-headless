# Дашборд динамики остатков

Генератор интерактивного Excel-дашборда по выгрузке остатков вида
«Остатки по дням» (строки — комбинации *Артикул × Размер × Склад*,
столбцы — остатки по дням).

## Запуск

```bash
pip install openpyxl pandas
python build_dashboard.py <input.xlsx> [output.xlsx] [--sheet "Остатки по дням"]
```

- `input.xlsx` — исходная выгрузка. Ожидаемые столбцы: `Артикул продавца`,
  `Размер`, `Склад`, далее по одному столбцу на каждый день (заголовок — дата).
- `output.xlsx` — файл дашборда (по умолчанию `dashboard.xlsx`).
- `--sheet` — имя листа с данными (по умолчанию берётся первый лист).

## Обработка данных

- **Консолидация размеров.** Остатки суммируются по каждому
  `(Артикул × Склад)`, размерность «Размер» в дашборде отсутствует —
  остаётся общее количество.
- **Отсев нулевых складов.** Строки `(Артикул × Склад)`, где остаток равен
  нулю за весь период, отбрасываются. В списке складов и на листе
  «По складам» остаются только склады с реальным остатком.

Глобальные суточные итоги при этом не меняются — удаляются только нули.

## Что внутри

| Лист | Назначение |
|------|------------|
| **Дашборд** | 2 выпадающих фильтра (Артикул / Склад, значение `ВСЕ` = без фильтра), KPI-карточки и график динамики остатка. Считается на живых `SUMIFS` — при смене фильтра всё пересчитывается. |
| **По артикулам** | Таблица по всем артикулам × дням + изменение шт./%, цветовая шкала, топ-15 по снижению. |
| **По складам** | Сводка по складам с реальным остатком + график топ по движению. |
| **Данные** | Консолидированный снимок (Артикул × Склад × дни) — на него ссылаются формулы дашборда. |

## Заметки по реализации

- Фильтр `ВСЕ` реализован без wildcard: критерий `SUMIFS` = `"<>"`
  (совпадает с любой непустой ячейкой), поэтому работает и в Excel,
  и в LibreOffice без включённой поддержки подстановочных знаков.
- Сводные листы (`По артикулам`, `По складам`) содержат значения,
  посчитанные из снимка, а не тысячи живых `SUMIF` — так книга остаётся
  лёгкой. Интерактивным остаётся лист **Дашборд**.
- У книги выставлен `fullCalcOnLoad`, поэтому формулы пересчитываются
  автоматически при открытии в Excel / LibreOffice.
