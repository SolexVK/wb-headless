# 15. Юнит-экономика и рыночные бенчмарки (оцифровка)

> Финансовая сторона: сколько реально забирает маркетплейс и что считать «своей» управляемой зоной.
> Данные — из презентации сервиса оцифровки (≈3,5 тыс. клиентов), приведены как ориентир.

## 1. Оцифровка — суть

- **Ядро отчётности = приход на расчётный счёт** — единственная цифра, которую можно проверить в
  кабинете маркетплейса. От неё «пляшут» все отчёты.
- Управляемая продавцом зона = **своя цена** (цена продавца). От оборота в цене продавца WB считает
  свои поборы; цена клиента (после СПП) — зона налогообложения.
- Ретро-данные (с 2022) помогают «реанимировать» товары, выведенные из ассортимента, когда конкуренция
  в их категории опустела.
- **Самовыкупы / DBS вычленяют** из отчётности, чтобы видеть реальную прибыль без «искусственных» продаж.

## 2. Бенчмарки WB (2025, ориентир)

| Показатель | Значение |
|-----------|----------|
| Средняя **грязная** маржинальность | ~**17,9%** |
| Косты вне себестоимости | ~10% |
| Реальная **чистая прибыль** | ~**7%** |
| **Поборы маркетплейса** (без налога) | 2022: 27,5% → 2023: 33,5% → 2024: 39,5% → **2025: 48,2%** |
| Продвижение (реклама) | 2022: 0,3% → 2023: 2% → 2024: 4,7% → **2025: ~6,5%** |
| Логистика | 8% → 9% → 11,6% → **12%** |
| Налоги | растут (2025 ~4,2% и выше) |
| Средний чек продавца vs цена клиента | **3769 ₽** (продавец) vs **2736 ₽** (клиент, после СПП) |

> Интерпретация: продавая за 1000 ₽, продавец отдаёт маркетплейсу ~**480 ₽** (без налога). При чистой
> прибыли ~7% цена ошибки очень высока — «шаг влево/вправо» уводит в минус.

## 3. Ozon (сравнение)

- Доля поборов в среднем **сопоставима** с WB.
- **Продвижение дороже**: рекламная система обучаемая, **не любит частых изменений ставок/бюджетов**
  (в отличие от привычки WB-продавцов ставить бидеры и менять ставки поминутно; WB тоже идёт к
  обучаемой модели).
- Логистика на Ozon ~**16,5%** (начинали с 12%).

## 4. СПП — управляемость

- **СПП неуправляема**: «скачет как кардиограмма», случаются отмены. Ориентироваться на **свою** цену.
- Механику min/max СПП (ВБ-кошелёк, категорийные пороги) см. [12 §1](12-reklama-prodvizhenie.md) и
  [05 §7](05-cena-i-cenovaya-segmentaciya.md).

## 5. Практические выводы

- Продавать на **нескольких маркетплейсах** («яйца по корзинам»): при смене условий одного перекрыться
  другим.
- Считать юнит-экономику **до запуска** (закладывать логистику/комиссии/продвижение/налог); при чистой
  прибыли ~7% ошибка в габаритах/цене критична (пример: логистика «съела» 56% реализации из-за
  неверных габаритов).
- Для инструментов: если считаем прибыльность ниши, закладывать поборы **~48% (2025)** как базовый
  ориентир и вычитать самовыкупы.
