# 13. Принадлежность запроса

> Центральный (и раньше «закрытый») механизм: соответствие товара ожиданиям запроса. Определяет,
> в какие запросы вообще стоит идти и почему у карточки низкий CTR/нет заказов.

## 1. Что это

**Принадлежность** — связь запроса с потребителем, характеристиками товара и ожиданием пользователя.
Чем точнее товар соответствует ключевым словам и ожиданиям запроса, тем выше шанс быть замеченным и
купленным. WB ввёл отдельный ИИ-алгоритм, определяющий принадлежность ключа к нише (см.
[11 §1](11-seo-optimizaciya.md)).

Критерии принадлежности (совпадают с «5 факторами» и критериями супер-карточки):
категория · материал · назначение/использование (контекст) · стиль · целевая аудитория (соц-сравнение)
· ценовая категория · тренды · сезонность · размер · функциональность · **конструктивные элементы** ·
**цвет**.

## 2. Метод анализа (Wildbox % соотношение)

Инструмент: **Wildbox → SEO → «Запросы у топов поиска»** (глубина топ-100). Wildbox проходит по топ-100
карточкам, смотрит, какие запросы у них растут, и объединяет их в **группы с процентом присутствия**
(у скольких % топ-карточек этот признак/запрос встречается в топе).

Шаги (для будущего инструмента):
```
1) Ввести главный запрос → «Сформировать» → выгрузить таблицу % соотношения
2) Разложить свой товар на СЕГМЕНТЫ и ПОДСЕГМЕНТЫ (материал, назначение, стиль, ЦА, цена,
   тренд, размер, функциональность, конструктив, цвет)
   — можно через ChatGPT: приложить фото + структуру сегментов → «разложи на подсегменты, что видишь»
3) По каждому признаку проверить % присутствия в запросе (поиск по колонкам)
4) Признаки с % < ~30 — вход в запрос закрыт; ≥ высоких % — обязательны
```

## 3. Порог входа (% как решающий критерий)

- **% присутствия признака = порог входа в запрос.** Пример «костюм мужской тёплый»: **капюшон — 84%**
  топа. Если вы **без капюшона**, у вас лишь **16%** шанс войти в этот запрос — низкий CTR, слив
  бюджета, некорректное позиционирование. Вывод: работать с **другим** запросом или позиционироваться
  **ниже** (2–3 страница, места 100+).
- Это объясняет, «почему в высокочастотном запросе не бустимся, нет кликов/корзин/заказов»: товар не
  подходит по новому критерию принадлежности.

## 4. Примеры (реальные %)

| Ниша | Ключевые признаки и % |
|------|----------------------|
| Костюм мужской тёплый | капюшон 84%, мембрана/флис в тепле |
| Рюкзак для ноутбука | «ручная кладь» 18% (нужна лямка на чемодан), для мужчины 60%, для ноутбука 76%, чёрный 28%, серый/белый, городской 44% |
| Комбинезон зимний для девочки | **мембрана 86%**, тёплый 80%, зима ~96%, горнолыжный 42%, чёрный 28%, коричневый 15%, утеплитель **200 г — 30%** (меньше граммовки → ниже рейтинг), размеры 116–122 у 68%, 140–152 у 40% |
| Набор для творчества | «8 лет» 60%, «6 лет», смола эпоксидная 16%, «мастер-класс» (QR на YouTube/VK), рукоделие/хобби (многоразовость) |

Вывод по примерам: признаки с высоким % **выносить на первое фото** (мембрана — «кричать» на первом
фото, т.к. у конкурентов её часто нет). Размер/возраст на фото подбирать под ЦА и цену (дорогой
горнолыжный → девочка постарше 140–158; повседневный дешевле → 5–6 лет).

## 5. Цвет — важнейший критерий принадлежности

- Неправильный цвет = **не зайти** в запрос. Проверять: **анализ топов поиска → свойства/характеристики
  → цвета**.
- «Серый серому рознь», «бежевый бежевому рознь» — есть конкретный оттенок, который берут лучше всех.
  Кейсы: «правильный» бежевый заработал больше чёрного+серого и подтянул их; **фуксия vs розовый** (люди
  воспринимали фуксию как красный) — переименование цвета дало рост; «горький шоколад» (см. [09 §3](09-podbor-tovara-supr-kartochka.md)).
- Если цвет вне тренда запроса (голубой/фиолетовый там, где нужен чёрный/серый) — шанс минимален.

## 6. Как использовать

1. Подобрать **3–5 запросов**, где карточка максимально подходит по принадлежности.
2. По ним строить **SEO** ([11](11-seo-optimizaciya.md)), **воронку/смыслы листинга** ([03](03-listing-infografika.md)) и **рекламу** ([12](12-reklama-prodvizhenie.md)).
3. Заложить принадлежность **на этапе подбора товара** ([09](09-podbor-tovara-supr-kartochka.md)) — тогда
   изначально сильнее конкурента.
4. Если не подходишь по главному запросу — **позиционироваться ниже** и работать с узкими запросами,
   пока не накопишь конверсию.

> ⚠️ Процентный анализ принадлежности — только **Wildbox**; MPStats его в таком виде не отдаёт.
> Частично воспроизводимо через MPStats по характеристикам SKU и цветам категории.
