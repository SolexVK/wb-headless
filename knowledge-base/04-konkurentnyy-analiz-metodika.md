# 04. Методика конкурентного анализа (листинг + смыслы)

> Пошаговая «партизанская» методика: как выбрать конкурентов, разобрать их листинг и
> смыслы и усилить свою карточку. Это ядро для будущего инструмента конкурентного анализа.

## 0. Этапы (обзор)

1. Первичный анализ карточки конкурентов (бот, мониторинг карточки).
2. Таблица анализа листинга (скриншоты слайдов в линейку).
3. Усиление смыслов листинга через **Gem** (команда Competition).
4. Доп. усиление в ассоциированных конверсиях и рич-контенте.
5. **Gem продвинутый** (рекомендации).

## 1. Отбор конкурентов: два сегмента → 5 уникальных карточек

**ДЗ №1.** Свой артикул → бот, команда **«мониторинг карточки товара»** (обновлённая; анализирует
топ-30 + полки + запросы + действия; факторы: цена, цвет, характеристики, конструктивный элемент).
Бот возвращает таблицу конкурентов по **рейтингу 1–6** (выше = больше трафика забирает).

Два сегмента:
- **Сегмент 1 (свой)** — анализ вашей карточки. Если вы в топ-6 — берёте конкурентов **до себя**
  (например, вы 4-й → берёте 1–4). Если ниже 6 — берёте топ-6.
- **Сегмент 2 (сильный)** — берёте **топа своего сегмента**, снова закидываете в бота, смотрите
  **его** топов (тоже до 6). Это подсвечивает реальных конкурентов, забирающих максимум трафика.
  Если во 2-м сегменте вы на 20-й / вас нет — ваш сегмент **слабый** (см. [02](02-zaprosy-podskazki-prinadlezhnost.md) §4).

Из объединения двух сегментов оставляете **5 уникальных карточек** (включая свою) — их и
анализируете. (5 — потому что Gem-Competition сравнивает до 5 карточек за 1 платное сравнение;
1 сравнение ≈ **140 ₽**.)

## 2. Таблица анализа листинга («маркетолог-партизан»)

**ДЗ №2.** Скриншот **каждого слайда** 5 карточек → в таблицу (Google-таблица / Miro), листинги
в линейку друг под другом. Тогда видны **закономерности** (у топов листинг очень схож).

Зачем таблица «прошлый листинг vs текущий»:
- Когда у конкурента **необоснованный рост** заказов (реклама/акции ни при чём) — он **поменял
  листинг** (переставил/заменил слайд). Фиксируем его листинг, через **1–2 недели** сравниваем,
  что изменилось → **копируем удачное**.
- Когда конкурент **упал** — смотрим, что он сломал, и **избегаем** этого у себя.

## 3. Теги смыслов из запросов (главный приём)

В любом запросе есть: **главное слово (категория)** + **«для кого»** (девочка/мальчик) +
**уникальное слово (хвост)**.

- Слово категории и «для кого» **не выписываем** — они априори должны быть (но на фото
  визуально показывать «для кого» **надо** — иначе покупатель не понимает применение).
- Выписываем **только уникальные слова из хвоста** запроса — это **триггеры конверсии**
  (осень, 4 года, детский садик, 104–110, «для лица», «набор»).
- Для товарки: не выписывать слово-предмет, но выписывать осмысленные слова решения о покупке.

### Распределение смыслов в листинге по частоте

- **Частотный** запрос → раскрывать **выше/раньше** в листинге (усиливаем в начале).
- **Менее частотный** → **ниже/позже**.
- Пример (костюм для девочки): «детский садик» (высокочастотный) — усилить в начале листинга
  (девочка в садике на фоне ящика) → рост конверсий в заказ; «тёплая осень с листочками»
  (частота ~23) — в конце (там уже незначительно).

## 4. Усиление смыслов через Gem — Competition

1. В Gem → **Competition** → сравнить карточки (добавляете по одному артикулу «Проверить»,
   до 5, затем «Сравнить карточки»).
2. Выгрузка — **таблица в архиве** → разархивировать → в боте команда `competition` → приложить
   таблицу → «пришлите ещё отчёт?» → «нет» → прислать **свой артикул** → бот генерирует итоговую
   таблицу **«смыслы конверсии»**.
3. Что делает бот: берёт все запросы, которые WB выдаёт (на разных листах), и по **каждому**
   проверяет конверсию (в корзину / в заказ) у **каждого** конкурента; строит картину
   **совпадения запросов** по всем конкурентам. Если у кого-то запроса нет — он внизу, конкуренту
   нули.
4. Читаем: где конкурент **сильнее** в запросе (выше конверсия в корзину/заказ) → заходим в его
   листинг → понимаем **почему** (как обыграл смысл) → повторяем/усиливаем у себя.
   - Пример: «костюм для девочки 5 лет» конверсия в корзину 18, в заказ 36–50 → на фото девочка
     «больше похожа на 5 лет», рост/фон садика → мама считывает возраст.

## 5. Keywords — метод без Gem

Если Gem нет — команда **Keywords** (анализ запросов карточки с 1-й по 4-ю страницу). Нужен
**Wildbox**.

- **Зоны позиций:**
  - Запросы с **1 по 399** позицию (жёлтая зона, до 4-й стр включительно) — **продажные** (есть
    конверсии/заказы). Вокруг них «танцуем»: листинг, оптимизация, реклама.
  - Запросы **400+** — практически **нулевые/непродажные**.
- Метод: аналитика карточки в Wildbox → над таблицей есть таблица запросов → берём жёлтую зону
  (1–399) → **всё оптимизация → группировка запросов** → Wildbox выдаёт **уникальные слова +
  частоту** → скачиваем → сравниваем по 5 карточкам (свой + конкуренты).
- Читаем **уникальные слова и их частоту**: где у конкурента слово чаще/качественнее собирается
  в оптимизации (без переспама) → оно лучше индексируется → усиливаем это слово у себя.
- Ограничения Wildbox: учитывает высокочастотные категории до частоты **0,03–0,04**,
  среднечастотные — до **~0,50**.

## 6. Достоверность данных аналитики

- WB отдаёт данные **за месяц**, но **еженедельно** их корректирует → **недельная** статистика
  вернее (в Радаре — за неделю). Внешние системы (Wildbox, MPStats, Market Guru) восстанавливают
  данные по остаткам/выкупам — считать их **оценочными**.
- Реальное число заказов конкурента через бота **не видно**; видно, как конкурент **растёт в
  запросах** (сигнал, что у него что-то поменялось).

## 7. Практический воркфлоу (для будущего инструмента)

```
1) Свой артикул → мониторинг карточки → таблица конкурентов (рейтинг 1..6)
2) Топ сегмента → повторный мониторинг → его топы
3) Отобрать 5 уникальных карточек (свой + 4)
4) Скриншоты слайдов → таблица листинга (линейка)
5) Gem Competition (или Keywords) → таблица смыслов/конверсий по запросам
6) Выделить теги смыслов (уникальные хвосты) + частоты
7) Распределить смыслы по листингу (частотные — выше)
8) Сверить со своим листингом → усилить слабые смыслы
9) Через 1–2 недели — пересравнить листинги конкурентов (что поменяли)
```

## 8. Связь с нашим MPStats-инструментом

У нас уже есть навык **wb-competitor-analysis** (см. `../.claude/skills/wb-competitor-analysis/`),
который через MPStats считает ёмкость ниши и топ-конкурентов по выручке/продажам. Он покрывает
**шаг 1–2** (кого анализировать) с точки зрения денег. Методика из этого урока добавляет
**качественный** слой (смыслы/листинг/теги), который стоит встроить в будущие инструменты:
- на вход — ниша/запрос; на выход — не только топ-продавцы, но и **теги смыслов** по запросам и
  чек-лист листинга.
- ⚠️ Часть данных (конверсии в корзину/заказ по слайду, «покупают также») MPStats **не отдаёт** —
  это только Gem/бот WB. Это ограничение нужно честно закладывать в инструменты.
