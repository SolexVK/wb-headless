# 14. Подбор ниши/товара через Wildbox (от спроса)

> Метод «от поискового спроса», а не от категорий: находим растущие ниши с деньгами через
> «Оракул запросов», проверяем сезонность/демпинг, собираем идеальный образ товара нейросетью.

## 1. Старый способ vs новый

- **Старый:** анализ категорий (тренды, коэффициент демпинга, перебор топ-карточек). Рутинно — в
  «Женщинам/брюки» ~16,5 тыс карточек, 100+ подтипов; трудно понять, что и когда продавать.
- **Новый (Wildbox):** отстройка **от спроса** — что растёт, туда и заходим. Инструменты в связке:
  **Оракул запросов → Анализ сезонности → Анализ топов поиска (ценовые сегменты) → нейросеть**.

## 2. Оракул запросов (фильтры)

Комбайн поискового спроса + финрезультат по топ-конкурентам. Ключевые фильтры:
- **Только новые запросы** (спрос зародился недавно) / все запросы.
- **Предметы** (искать спрос внутри конкретного предмета: юбки плиссе, вид чайника и т. п.).
- **Рейтинг качества ниши**: лучшие/хорошие/средние/плохие — оценка по **15+ показателям** (выручка,
  упущенная выручка, монопольность, % выкупа…). Плохие сразу исключать.
- **Частотность за 30 дней** (напр. от 5 000).
- **Динамика роста** за 30/60/90 дней (напр. +30% за 30 дней; для «весеннего» входа: +30% март,
  +15% февраль, падение в январе).
- **Количество артикулов** по запросу (конкуренция; напр. до 3 000–5 000).
- **% артикулов в рекламе на 1-й стр** (до 30% ⇒ >70% органики).
- **Спрос = частотность / количество артикулов** (напр. **10:1** и выше — высокий спрос на товар).
- Ещё: выручка топ-300, средняя выручка/карточку, монопольность, средняя цена, % внешнего трафика,
  % артикулов с продажами (порог трафика), % выкупа (для товарки от 85% отсекает одежду).

## 3. Чтение отчёта

Колонки: запрос · рейтинг · динамика · частотность · выручка топ-300 · ср. выручка/карточку · %
упущенной выручки · монопольность (топ-10 по выручке / топ-100) · ср. цена (без СПП) · % рекламы · %
внешки · конкуренция (кол-во артикулов) · спрос (X:1) · % артикулов с продажами (порог трафика) ·
**ср. кол-во отзывов** (мало отзывов у топа = молодая ниша) · % выкупа.
- Клик по запросу → **анализ частотности**: когда запрос зародился и растёт ли (пример: «юбка атласная
  с кружевом» появилась март-2025, спрос резко растёт).
- **Новинки в топе** (карточки моложе 14 дней): много новинок = тренд только зарождается, вход реален.

## 4. Анализ сезонности

Инструмент «Анализ сезонности» (по месяцам, 3 года):
- **Выручка на артикул** по годам/сезонам (весенний vs осенний товар; прогноз на след. год).
- **Коэффициент демпинга**: **0–15% — демпинга нет**, 15–30% — умеренный, **>30% — высокий** (не
  заходить). В сезон демпинг должен падать; если в сезоне растёт — ниша плохая.
- Вывод о лучшем окне входа (напр. конец января — начало февраля перед мартовским пиком).

## 5. Ценовые сегменты и идеальный образ

- **Анализ топов поиска (глубина топ-300) → ценовые сегменты**: количество артикулов, средний чек,
  заказы, выручка по сегментам → выбрать сегмент, где выручка на артикул выше при разумной конкуренции;
  можно выгрузить конкурентов сегмента в мониторинг для детального анализа.
- **Свойства и характеристики → нейросеть.** Скопировать аналитику названий/предметов и подробных
  характеристик топ-300 → в ChatGPT/DeepSeek с промптом:
  > «Ты аналитик-стилист. Сделай рекомендацию по профилю **идеального товара** в категории **[ниша]**
  > на **[год]**. Проанализируй модные дома и выяви тренды.»
  → «формула хита» (силуэт, длина, цвет, декор, посадка) + рекомендуемый **скелет карточки**.
- **Отзывы конкурентов**: выгрузить 1–2★ (негатив) и 4–5★ (позитив) в Excel (расширение/сервис) →
  нейросеть выделяет частые боли/плюсы → отстроить свою инфографику (закрыть боли, подсветить плюсы).

## 6. Итог

Связка **Оракул → сезонность → ценовые сегменты → нейросеть** даёт за ~5–10 минут: растущий спрос,
окно входа, деньги/демпинг, образ идеального товара и список конкурентов для углублённого анализа.
Дополняет «взгляд в прошлое → будущее» из [09 §7](09-podbor-tovara-supr-kartochka.md).

> ⚠️ Оракул запросов, коэффициент демпинга, % новинок, порог трафика — специфика **Wildbox**; MPStats
> даёт близкие данные частично (категории/тренды/сегментация цен).
