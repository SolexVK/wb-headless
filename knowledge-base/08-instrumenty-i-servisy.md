# 08. Инструменты и сервисы

> Сводка всех упомянутых в уроках инструментов: что делает, как и где применяется.

## Аналитика карточек и конкурентов

### Gem (Джем)
- Аналитический бот/сервис для WB. Тарифы: **базовый / стандарт / продвинутый**, есть версия на **Light**.
- Ключевые функции:
  - **Competition** — сравнение карточек (до **5** за 1 сравнение; сейчас правят с 2 до 5;
    1 сравнение ≈ **140 ₽**). Выдаёт таблицу **смыслов конверсии** по запросам всех конкурентов.
  - **Рекомендации** (в продвинутом) — управление блоком рекомендаций/ассоциированных конверсий.
    Кейс: 3 мес → 66 813 переходов, 819 заказов.
- Методика применения — [04](04-konkurentnyy-analiz-metodika.md).

### Пушка-бот (ИИ-агент)
- Функции: **анализ/мониторинг карточки** (команда «мониторинг карточки товара» — топ-30 + полки +
  запросы + действия; факторы: цена, цвет, характеристики, конструктивный элемент), генерация
  фото/видео. Команда `/start`.
- **Поисковые подсказки HITS** — закрытая функция, команда `hits`.
- Токены для курса: **бесплатно** (напр. 200 генераций на фото/ChatGPT/анализ; видео — по платному
  тарифу). Внутри: **Gemini 2 Pro** (автор считает её точнее GPT-5 для промптов), **Klink Turbo**,
  **Veo 3.1**.

### Wildbox
- Мониторинг: запросы, слова, характеристики, склады/доставка, склейки/цвета.
- Функции:
  - **Аналитика карточки** + таблица запросов (для метода Keywords).
  - **Всё оптимизация → Группировка запросов** — уникальные слова + частота.
  - **Анализ конкурентов / анализ топов поиска** — цвета/свойства/характеристики по запросу
    (принадлежность), ценовая сегментация.
  - **Сравнить анализ → Рекомендация** — топ-1/50/100 карточек и **откуда чаще отгружается** товар.
- Ограничения частот: высокочастотные категории учитывает до **0,03–0,04**, среднечастотные — до **~0,50**.

### MPStats / Market Guru
- Внешние аналитические системы. MPStats: количество отзывов в день/период, смыслы из отзывов,
  данные категории/продаж (оценочные).
- У нас реализован навык **wb-competitor-analysis** поверх MPStats API — см.
  `../.claude/skills/wb-competitor-analysis/` и `references/mpstats.md` (методы: `wb/get/categories`,
  `wb/get/category`, `.../sellers`, `.../brands`, `.../trends`, `.../price_segmentation`,
  `wb/get/item/{sku}/sales`).

### Достоверность данных
- WB отдаёт данные **за месяц**, но еженедельно корректирует → **недельная** статистика вернее.
  Внешние системы восстанавливают данные по остаткам/выкупам — считать **оценочными**.

## Реклама и цена

### Радар (ВБ Радар)
- Сервис работы с рекламой: стратегии, замер органики (с какой позиции идёте вверх), остановка
  запросов/полок (по мере поддержки WB). Для интенсива — **бесплатно на месяц**.
- Контекст изменений WB (на момент уроков): нельзя отключить запрос, пока не скрутил **100 показов
  на кластер**; WB убирает **минус-фразы**; интерфейс рекламы менялся, основные кластеры временно
  отключались.

### Репрайсер
- Инструмент управления **«красивой» ценой** и облегчения входа в акции. Единоразовая оплата
  (сервис «Саши»; автор использует ~5 месяцев). Детали — на отдельном вебинаре (ожидается).

## Соцсети / внешний трафик
- **Pinterest** — обязательно (насмотренность + внешний трафик; 5500 просмотров за неделю бесплатно).
- Инстаграм, YouTube — развивать; блогеры для видео-обзоров (кейс машинки от катышков).

## Отложенные темы (ожидаются в новых уроках)

- Реклама и продвижение (стратегии, бидер, кластеры, ассоциативные конверсии в РК).
- Формула цены для маркетплейса; влияние цены на % выкупа (эксперимент с оцифровкой).
- Отдельные вебинары: инфографика (расширенный), репрайсер, оцифровка/юнит-экономика.
