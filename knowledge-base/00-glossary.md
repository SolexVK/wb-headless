# Глоссарий

Термины в том значении, в каком их использует автор уроков.

| Термин | Значение |
|--------|----------|
| **Воронка продаж** | Путь покупателя: показ → клик → корзина → заказ → выкуп → отзыв. Каждый этап влияет на органику по-своему (см. [01](01-algoritm-ranzhirovaniya-voronka.md)). |
| **Органика** | Бесплатные (неоплаченные) позиции карточки в поиске/категории. |
| **Принадлежность** | Совокупность неявных признаков товара, «зашитых» в запрос: назначение, цвет, размер/возраст, стиль, оверсайз/приталенный и т. д. Ключевой фактор ранжирования. |
| **Смыслы** | Идеи/сообщения, которые фото и листинг доносят покупателю и которые алгоритм читает как теги (эмоция, проблема, ассоциация, функция…). |
| **Теги / альт-теги** | Слова-смыслы, «считываемые» алгоритмом с первых 5 фото; объясняют, почему покупатель выбирает товар. |
| **Листинг** | Последовательность фотографий карточки (первые 5–10 слайдов), выстроенная так, чтобы вести покупателя к заказу. |
| **Инфографика** | Оформление фото: текст, триггеры, смыслы на изображении. |
| **Первое фото / PRON (промпт)** | Главная фотография; «PRON» в уроках — это первая фотография как исходный смысловой промпт для остального листинга. |
| **Зона осмысления** | Первые 5 фото, которые покупатель листает ещё до входа в карточку — решает, стоит ли переходить. |
| **Зона принятия решения** | Дальнейшие слайды + отзывы/рич-контент внутри карточки, где принимается решение о заказе. |
| **Сегмент (сильный / слабый)** | Группа конкурентов. Сильный сегмент — карточки, забирающие максимум трафика; слабый — ваш текущий, если вы не топ. |
| **5 факторов топовости** | Визуал, характеристики, конструктивные элементы, социальное сравнение, представление/функциональность. См. [02](02-zaprosy-podskazki-prinadlezhnost.md). |
| **Социальное сравнение** | Сопоставление покупателя с моделью на фото (возраст, рост, комплекция) — влияет на то, в какую аудиторию попадёт товар. |
| **Матричный метод дополнения слов** | Механика, при которой WB добавляет карточке слова из запросов её покупателей (пример: «Pinterest», «бренд»). |
| **Поисковые подсказки** | Автоподсказки в строке поиска WB; первичные запросы, по которым сканируется карточка. |
| **Склейка** | Объединение вариаций товара (цвета/размеры) в одной карточке. |
| **СПП** | Скидка постоянного покупателя (назначается алгоритмом WB; при нарушениях может обнуляться). |
| **Полки** | Блоки «рекомендации/похожие товары»; ~15% трафика воронки. |
| **Ассоциированные (ассоциативные) конверсии** | Заказы других товаров, к которым покупатель перешёл из вашей карточки/рекламы. |
| **«Покупают также»** | Инструмент WB, показывающий сопутствующие товары; можно на него влиять. |
| **Рич-контент (rich-content)** | Расширенное вертикальное описание карточки из фото-блоков; по Ozon даёт ~50% дополнительного вовлечения. |
| **УТП** | Уникальное торговое предложение. |
| **ДРР** | Доля рекламных расходов. |
| **CTR** | Кликабельность (переход в карточку из выдачи). |
| **CR2** | Конверсия в заказ. |
| **АБТ-тестирование** | A/B-тест карточки/инфографики. |
| **Gem (Джем)** | Аналитический бот/сервис для WB: сравнение карточек (Competition), смыслы конверсий, рекомендации. Тарифы: базовый/стандарт/продвинутый, есть на Light. |
| **Пушка-бот** | ИИ-агент (в уроках): анализ карточки, генерация фото/видео (nano-banana, Veo, Klink, Gemini). |
| **Keywords** | Функция анализа запросов карточки с 1-й по 4-ю страницу (замена Gem при его отсутствии). |
| **Wildbox** | Аналитический сервис (мониторинг запросов, слов, характеристик, складов, склеек). |
| **MPStats / Market Guru** | Внешние аналитические системы по WB. |
| **Радар (ВБ Радар)** | Сервис для работы с рекламой (стратегии, органика, минусация — по мере поддержки WB). |
| **Шторм 2.0** | Недельная стратегия рекламы: ежедневное чередование АРК/АУК, работа с диапазоном ставки и первой фотографией для обучения алгоритма. См. [16](16-shtorm2-arka-auk-strategiya.md). |
| **АРК** | Автоматическая рекламная кампания (единая ставка): расширение аудитории «вширь». |
| **АУК** | Аукцион (ручная ставка): сужение — работа с нашей аудиторией, стабильнее; единственный способ влиять на полки (через рекомендации). |
| **Целевая позиция** | Стратегия Радара: держит карточку в заданном диапазоне мин–макс ставки. |
| **Многорукий бандит** | Агрессивная стратегия Радара (90% ротация): не останавливается, толкает выше, бонус за сработанный заказ. |
| **Математически обоснованное исследование / Баланс исследования** | Более стабильные стратегии Радара (30–70% / 30–40% исследования) для разогнавшихся карточек. |
| **Шаг / итерации** | Прохождение диапазона ставки равными долями: шаг = (макс−мин)/число итераций (обычно 5–8/день). Алгоритм лучше реагирует на нечётные числа. |
| **Затухание** | Параметр цели Радара: сколько прошлых данных учитывать (48 ч). Затухание 0 = игнорировать прошлое, искать заново. |
| **Красная зона** | Поле минус-фраз: плохой запрос грузят туда сразу (в 13:00), не дожидаясь автопадения после 100 показов. |
| **Идентификатор поисковой выдачи** | Высший уровень персонализации WB: анализирует лучшую инфографику и распределяет карточку по аудиториям в рамках кластера. |
| **Персонализированная выдача** | Разным аудиториям карточка показывается на разных позициях (критерии: история покупок/просмотров, клики, запросы, отзывы, рейтинг, локализация, возраст, пол). |
| **Реклама на главную** | Вывод товара на 1-ю страницу WB через главные запросы; ключевой фактор — аудитория. См. [17](17-reklama-na-glavnuyu-podborki.md). |
| **Подборка / промо-выдача** | Рассылка WB (push-уведомления) по подборке товаров целевой аудитории; окно воздействия 15–20 мин, история уведомлений видна на Android 14+. |
| **Коэффициент показов** | Множитель ставки за 1000 показов (коэф. 1 = 500 ₽). На карточке/главной ниже (0.7–0.9) — скидка WB за больший трафик. |
| **ВБ-кошелёк** | Инструмент WB, влияющий на «красивую» цену и СПП (планируется к отмене). |
| **Репрайсер** | Инструмент автоматического управления «красивой» ценой для входа в акции. |
| **nano-banana** | Нейрогенератор изображений (в боте). |
| **Veo / Klink** | Нейрогенераторы видео (Veo 3.1, Klink Turbo). |
| **Апскейлер** | Программа повышения детализации фото (768×1344 → 3072×5376). |
| **GoLogin** | Виртуальный браузер с прокси для доступа к зарубежным ИИ-сервисам. |
| **FlatLay** | Раскладка товара на плоскости (без модели). |
| **Товарка** | Непродуктовые товары (не одежда): техника, косметика, бытовые товары. |
