## Что добавлено (Фаза 4B — Инфраструктура)

### runtime/ — Жизненный цикл проекта
- `runtime/runtime.py` — `RuntimeEngine`
- 7 статусов: CREATED → INITIALIZED → ACTIVE → EXPORTING → EXPORTED → ARCHIVED / FAILED
- Валидация переходов (нельзя ACTIVE → CREATED)
- Событийная система: `on(status, handler)`, `on_any(handler)`
- История событий для каждого проекта
- Трекинг текущей фазы когнитивного цикла
- Фильтрация проектов по статусу

### memory/ — Протокол памяти CP-001.4
- `memory/memory.py` — `MemoryStore`
- `store(key, value, namespace)` — сохранить (с overwrite)
- `read(key, namespace)` — прочитать
- `search(query, namespace, limit)` — поиск по ключам/значениям с релевантностью
- `delete(key, namespace)` — удалить
- `clear(namespace)` — очистить namespace
- Namespace isolation (M-003): `user.preferences`, `project.{id}.facts`, `domain.{name}`, `system.{version}`
- Versioned entries (M-002): createdAt, updatedAt, agentID

### sdk/ — Публичное API
- `sdk/vcos_client.py` — `VCOSClient` + `Session`
- `create_session(category)` — создание сессии
- `ask(session_id, message)` — когнитивный цикл
- `select_profile(session_id, name)` — выбор профиля
- `export(session_id, model)` — экспорт промпта
- `fork(session_id, branch_name)` — ветвление проекта
- `diff(session_a_id, session_b_id)` — сравнение веток
- `search_memory(query, namespace)` — поиск в памяти
- `remember(key, value, namespace)` — сохранение в память
- Интеграция с RuntimeEngine (status transition, phase tracking)
- Интеграция с MemoryStore (авто-сохранение фактов сессии)
