# Contributing to VCOS

Спасибо за интерес к VCOS! Вот как ты можешь участвовать.

## Принципы

1. Все изменения начинаются с ADR или RFC
2. Никаких изменений 000-foundation — он неизменяем
3. Каждый документ имеет версию и статус
4. Ссылайся на инварианты, не дублируй их

## Процесс

### Для нового RFC
1. Создай копию `docs/templates/rfc/TEMPLATE.md`
2. Размести в соответствующей директории `docs/standard/`
3. Отправь на Review
4. После утверждения — меняй статус на Approved

### Для нового ADR
1. Создай копию `docs/templates/adr/TEMPLATE.md`
2. Размести в `docs/standard/900-adr/`
3. Укажи, на какие инварианты и принципы ссылается решение

### Для изменения существующего документа
1. Создай ADR с обоснованием изменения
2. Обнови версию документа
3. Добавив запись в CHANGELOG.md

## Стиль

- Используй терминологию CO-001
- Избегай дублирования информации
- Каждый документ должен быть самодостаточным (с ссылками на parent)
- Примеры — обязательны
