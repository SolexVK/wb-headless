# Product Card Criteria — Критерии для карточки товара

Справочник категорий товаров и их специфических вопросов для VCOS.
Каждая категория — свой набор уточняющих вопросов перед формированием промпта.

---

## 🧥 ОДЕЖДА

**Вопросы:**
- Тип: рубашка / футболка / платье / костюм / пальто / нижнее бельё / верх
- Ткань: муслин / хлопок / трикотаж / шёлк / деним / кожа / шифон
- Крой: свободный / приталенный / оверсайз / прямой / трапеция
- Воротник: отложной / стойка / V-вырез / хомут / без воротника
- Рукав: длинный / короткий / 3/4 / реглан / без рукавов
- Линия плеча: естественная / спущенная / подплечники / реглан
- Посадка на модели: облегает / струится / держит форму
- Размер на модели: какой размер демонстрируем
- Застёжка: пуговицы / молния / запах / на кнопках

---

## 👗 ОБУВЬ

**Вопросы:**
- Тип: кроссовки / туфли / сапоги / босоножки / кеды / угги
- Каблук: плоский / низкий / высокий / шпилька / танкетка / платформа
- Носок: круглый / острый / квадратный / открытый
- Материал верха: кожа / замша / текстиль / экокожа
- Цвет: основной + комбинация
- Сезон: лето / зима / демисезон / всесезон
- Вид: сзади / сбоку / сверху / на ноге / flat lay
- Размерная сетка: до какого размера

---

## 💄 КОСМЕТИКА

**Вопросы:**
- Тип: помада / тени / тональный / крем / парфюм / тушь
- Текстура: матовая / глянцевая / кремовая / жидкая / пудровая
- Оттенок: конкретный цвет + номер/название
- Упаковка: флакон / тюбик / баночка / стик
- Как показать: сам продукт / на коже / свотч / в использовании
- Эффект: сияние / матовость / увлажнение / стойкость

---

## 🧴 УХОД И БЫТОВАЯ ХИМИЯ

**Вопросы:**
- Тип: шампунь / гель / крем / порошок / спрей
- Объём / вес: флакон целиком или крупно этикетка
- Форма флакона: круглая / квадратная / фигурная / дозатор
- Консистенция: жидкая / гелевая / кремовая / порошок / твёрдая
- Цвет упаковки + цвет содержимого
- Пена / текстура / капли (динамика)
- Стиль фото: минималистичный / премиальный / домашний

---

## 🍫 ЕДА И ПРОДУКТЫ

**Вопросы:**
- Тип: сладкое / снеки / соусы / полуфабрикаты / напитки
- Упаковка: коробка / пакет / банка / бутылка
- Подача: готовое блюдо / в упаковке / процесс приготовления
- Состояние: горячее (пар) / холодное (лёд, конденсат) / комнатное
- Текстура: хрустящее / сочное / жидкое / слоёное / расплавленный сыр
- Сервировка: тарелка / скатерть / фон / приборы
- Стиль: фуд-фото / минимализм / натюрморт / lifestyle

---

## 🪑 ДЕКОР И ИНТЕРЬЕР

**Вопросы:**
- Тип: светильник / ваза / рамка / панно / подушка / свеча
- Материал: керамика / дерево / стекло / металл / текстиль
- Цвет: основной + оттенок
- Стиль: лофт / скандинавский / классика / минимализм / бохо
- Масштаб: в интерьере / flat lay / на нейтральном фоне
- Освещение: каким светом подсветить фактуру

---

## 📱 ЭЛЕКТРОНИКА И ГАДЖЕТЫ

**Вопросы:**
- Тип: наушники / зарядка / чехол / колонка / гаджет
- Экран: включён / выключен / что на экране
- Материал корпуса: матовый / глянцевый / металл / силикон
- Разъёмы / порты: видны ли, важны ли
- Размер: в руке / на столе / с предметом для масштаба
- Световые эффекты: индикаторы, подсветка, отражения
- Фон: студийный / технологичный / lifestyle

---

## 🧸 ТОВАРЫ ДЛЯ ДЕТЕЙ И ИГРУШКИ

**Вопросы:**
- Тип: игрушка / одежда / мебель / питание
- Ребёнок: есть в кадре / нет / показать в игре / flat lay
- Возрастная группа: 0+ / 3+ / 6+ / 12+
- Палитра: мультяшная / пастельная / натуральная
- Масштаб: в руке / на фоне детской
- Безопасность: для малышей — убрать мелкие детали

---

## 🏠 УНИВЕРСАЛЬНАЯ

Для товаров без категории выше.

**Вопросы:**
- Что за товар: свободное описание
- Форма / геометрия
- Материал / текстура
- Основной цвет
- Типичное использование
- Стиль фото: студийный / lifestyle / предметный
