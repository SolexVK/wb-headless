# Handoff — FBS-сервис (Wildberries фулфилмент-аналитика)

## Цель
Мультитенантный веб-сервис аналитики FBS по Wildberries: организации/участники,
подключение WB-кабинета (токен шифруется AES-256-GCM), отчёты по фулфилмент-складам.
Хостится на Mac Mini, наружу отдаётся через Tailscale + Caddy:
**https://mac-mini-vital.tail13d29e.ts.net/fbs/**. Код в `service/`, ветка разработки
`claude/fbs-fullfilment-branch-cfvgir`. Скрипты-пайплайны — в `scripts/`.

## Текущее состояние
Работает и протестировано (все smoke-тесты зелёные). Три отчёта:
- **Подсорт** — рекомендации к дозаказу по складам/размерам + пробный завоз.
- **Остатки** — текущий остаток FBS по складам и артикул+цвет; ежесуточный
  автоснимок (копит историю), выбор даты из архива, выгрузки.
- **Движение заказов** — принято/передано по дням и складам; ₽ по трём базам
  (себестоимость 620/шт, ср. цена продажи 7д из статистики, цена заказа);
  тумблеры показатель/единица/база/разбивка/оверлей/сравнение/склады.

Общее для всех отчётов: KPI-карточки + «Выводы» (инсайты) + панели с иконками,
графики с тултипами при наведении, сортируемые таблицы, выгрузки
**Excel / JSON / 📊 HTML-дашборд / 📄 PDF**, общий архив компании (90 дней),
единый дизайн (свет/тёмная тема), лёгкий градиентный фон.

Деплой на Mac Mini: launchd `com.wbheadless.fbs`, слушает 127.0.0.1:9110,
Caddy проксирует `/fbs`. Обновление одной командой: `zsh /tmp/fbs-up.sh`
(git pull ветки + npm test + `launchctl kickstart -k gui/$(id -u)/com.wbheadless.fbs`).
Путь репозитория на Mac Mini: `/Users/openclaw/wb-fbs` (сервис в `.../service`).

## Файлы, над которыми работали
- `service/views.js` — весь серверный рендер: страницы отчётов, KPI/инсайты/панели,
  in-app графики (mvChart с тултипами), сортируемые таблицы, сводная подсорта
  (Остаток|Подсорт, заморозка 3 столбцов), токены темы + градиентный фон, подключение
  общего интерактив-слоя.
- `service/reports.js` — маршруты отчётов, `sendDownload` (json/xlsx/html/pdf),
  имена файлов «Название отчёта дата», архив с фильтром по типу.
- `service/reports-runner.js` — пайплайны (podsort/stock/movement), single-flight,
  builder'ы Excel/HTML-дашбордов, `dashboardToPdf` (спавнит html-to-pdf.mjs).
- `service/scheduler.js` — ежесуточный автоснимок остатков (идемпотентно, раз в час).
- `service/smoke-reports.mjs` — тесты отчётов (fake-режим PODSORT_FAKE).
- `scripts/lib/dashboard-kit.mjs` — дизайн-кит дашбордов (CSS, KPI, панели, графики
  line/bar/donut/hbars с тултипами, page/artifact с инлайн JS/CSS).
- `scripts/lib/report-interactive.mjs` — общий клиентский JS+CSS: тултипы графиков,
  сортировка таблиц, заморозка столбцов (.frozen3), .print-hide.
- `scripts/fbs-movement.mjs` — сбор движения (orders+supplies+sales), серия по дням.
- `scripts/fbs-{stock,movement,replenishment}-dashboard.mjs` — HTML/PDF-дашборды.
- `scripts/html-to-pdf.mjs` — рендер HTML→PDF **системным** Chrome (`--print-to-pdf`).
- `scripts/fbs-xlsx.py` — Excel подсорта; лист «Сводная» = Остаток(серый)+Подсорт(зелёный).
- `scripts/fbs-{stock,movement}-xlsx.py` — Excel остатков/движения.

## Что изменилось (по сути, за последние сессии)
- Добавлен отчёт **Движение заказов** (единый пайплайн для «принято»/«передано»).

  паритет стиля между дашбордами и страницами приложения.
- **Интерактив**: тултипы на всех графиках (кроссхэйр+значения), сортировка таблиц
  кликом по заголовку (двигается вся строка, числа как числа через `data-v`).
- **KPI без дублей**: инсайты не повторяют плитки (подсорт → критично/завоз;
  движение → пик отгрузки; остатки → топ-3 склада %).
- **Имена файлов**: «Подсорт 2026-08-14.xlsx» и т.п. (кириллица через res.attachment/download).
- **Excel подсорта «Сводная»**: слева Остаток по складам, справа Подсорт (после
  «Ост.Итого»); блок Подсорт выделен зелёным (шапки+ячейки).
- **Градиентный фон** всего сервиса (свои оттенки для светлой/тёмной темы, ненавязчиво).
- Себестоимость по умолчанию 620 ₽/шт (правится в тумблере движения без пересбора).

## Что пробовали и НЕ сработало (важно!)
- **PDF через npm-пакет `playwright`** — на Mac Mini падало
  `Cannot find package 'playwright'` (в корне репо `node_modules` нет playwright;
  ставили только `service/`). РЕШЕНИЕ: `scripts/html-to-pdf.mjs` больше НЕ импортирует
  playwright — вызывает **уже установленный системный** Chrome/Chromium/Edge/Brave
  флагом `--print-to-pdf`. Ищет бинарник по типовым путям macOS/Linux + Playwright/
  Puppeteer каталогам; путь можно задать `WB_CHROME`. Пробует `--headless=new`, затем `--headless`.
- **WB не отдаёт исторические остатки FBS** — `POST /api/v3/stocks/{id}` только текущие,
  параметра даты нет. Поэтому «остатки на дату» = выбор из СВОИХ накопленных снимков
  (report_runs) + ежесуточный автоснимок. Не пытаться просить дату у WB.
- **WB `/api/v3/orders` не принимает окно > ~30 дней** (400 IncorrectParameter) —
  тянем кусками ≤28 дней с дедупом по id.
- **Статистика `/api/v1/supplier/sales` — лимит 1 запрос/мин** (перс./серв.). Один
  вызов на прогон движения; поэтому первый сбор движения дольше.
- **Широкие таблицы уезжали за край в PDF (портрет)** — перешли на **альбомную**
  ориентацию (`@page size:A4 landscape`) + печатный CSS (таблица 100%, перенос текста,
  мелкий кегль). В сводной подсорта в PDF блок «Остаток» скрывается (`.print-hide`),
  печатается как раньше (Подсорт+Итого).
- **Прыжок страницы вверх при клике на тумблер движения** — добавлен якорь `#mv`
  на блок результатов (+ `scroll-margin-top`), форма себестоимости submit туда же.
- **Чёрный цвет на графиках/чипах** — заменён: линия «Итого» = `var(--total)` (индиго)
  и толще; активные чипы = `var(--accent)` (индиго). Пользователь просил без чёрного.
- **Тёмная тема в HTML-дашбордах** — форсируем светлую: `<html data-theme="light">`.
- **Chromium в этом облаке** лежит по версионному пути
  `/opt/pw-browsers/chromium-1194/chrome-linux/chrome` (НЕ просто `/opt/pw-browsers/chromium`).
  Для скриншотов Playwright указываем `executablePath` явно; в `html-to-pdf.mjs`
  резолвер это учитывает (глоб `chromium*/chrome-linux/chrome`).
- **LibreOffice `--convert-to pdf`** в облаке НЕ сработал (визуально Excel не
  превьюим) — цвета заливок проверяли программно через openpyxl (это и есть истина).
- **Excel по подсорту НЕ покрыт smoke-тестом** (fbs-xlsx.py требует полный
  fbs-replenishment.json; smoke использует fake-снимок и тестит только JSON). Изменения
  в fbs-xlsx.py проверяем ручным прогоном (см. ниже).

## Команды для проверки
```bash
# Тесты сервиса (из каталога service):
cd service && npm test          # smoke-test + smoke-basepath + smoke-reports

# Синтаксис отдельного файла:
node --check service/views.js

# Ручной прогон Excel подсорта (нужен reports-output/fbs-replenishment.json):
D=/tmp/xlcheck && mkdir -p $D && cp reports-output/fbs-replenishment.json $D/ \
  && REPORTS_OUTPUT_DIR=$D python3 scripts/fbs-xlsx.py

# Ручной прогон HTML-дашбордов (движение отдаёт снимок = снимок сервиса):
node scripts/fbs-movement.mjs --days 14 --json > $D/fbs-movement-service.json \
  && REPORTS_OUTPUT_DIR=$D node scripts/fbs-movement-dashboard.mjs

# PDF из дашборда (нужен системный Chrome; в облаке — /opt/pw-browsers/chromium-*/):
node scripts/html-to-pdf.mjs $D/fbs-movement-dashboard.html $D/out.pdf --landscape
```
**Ожидаемое состояние (зелёное):** `npm test` → три строки «…все проверки зелёные»
(smoke-test / BASE_PATH / Отчёты Ф2). PDF-проверка в smoke мягкая: если Chromium в
среде есть — строгая проверка сигнатуры `%PDF`, если нет — «пропущен» (не падение).
Красных быть не должно. Если `npm test` не зелёный — это регресс, не «те самые».

## Открытые вопросы (нужно решение пользователя)
- **«Динамика остатков по фулфилменту» (график)** — отложено осознанно: нужен
  накопленный автоснимками объём (4–7 дней). Вернуться, когда наберётся история.
  ЖДУ: сигнала пользователя, что данных достаточно / что делаем этот отчёт.
- **Себестоимость: единая 620 ₽/шт vs пер-артикул** — сейчас единая (правится в
  тумблере). Рекомендация: при желании точности — таблица себестоимостей по артикулам.
  ЖДУ ОТВЕТА, если понадобится.
- **PDF на Mac Mini** — зависит от наличия системного Chrome. Если кнопка «📄 PDF»
  ругнётся «не найден Chrome» — либо `WB_CHROME=/путь` в `.env`, либо печать из
  браузера (HTML-дашборд → Печать → Сохранить как PDF). Нужен вывод
  `ls "/Applications/Google Chrome.app/Contents/MacOS/"` с Mac, чтобы подтвердить путь.
