# Handoff — Аналитика Wildberries (анализ ниши + топ товаров)

## Цель
Набор инструментов оценки WB по данным MPStats:
1. **Анализ ниши/категории** — ёмкость, сезонность, тренд, конкуренция, насыщенность → скоринг 0–100
   и вердикт «заходить/осторожно/не заходить» + реализация остатка, экономика, Оракул, PDF. (влито в main)
2. **Топ-N товаров** (новое в этой сессии) — конкретные товары-лидеры категории по выручке с фото,
   ссылками, брендом, остатками/складами и динамикой; PDF + интерактивный HTML.
Оба — запускаются на любой категории/фильтре (CLI + скилл).

  картинки видны и в PDF, и в HTML без внешней загрузки. Hover-zoom — CSS `transform: scale` (в
  печати отключён).
