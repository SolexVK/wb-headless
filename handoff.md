## Что пробовали и НЕ сработало
Сегодняшнее:
- **«Бесплатный ПВЗ» как рычаг экономии** — главная ошибка вчерашнего разбора. Вывод строился
  на окне, где день выдачи ещё не был закрыт. Правило на будущее: **отсутствие начислений в
  окне ничего не доказывает**, пока не закрыт день выдачи; сравнивать можно только закрытые дни.
  В коде это теперь зашито: `quietPvz` — диагностика, а не экономия.
- **«В базовом периоде такой причины не было» для возвратной логистики** — формально верно,
  по смыслу вводит в заблуждение: списания приходят пакетами раз в несколько дней. Решено
  флагом `batched` в каталоге: для таких типов важность не повышается.
- **Секреты в чат или в команду терминала** — так делать нельзя: чат сохраняется, а команда
  оседает в `~/.zsh_history` открытым текстом. Решение: только локальный `.env` (600), а все
  проверки печатают маску.
- **`#`-комментарии в командах для терминала Mac Mini** — на этом Mac в zsh интерактивные
  комментарии выключены, строка с `#` выполняется как команда. В инструкциях их нет.

Вчерашнее (актуально):
- `statistics-api /api/v5/supplier/reportDetailByPeriod` в актуальной документации отсутствует —
  живой метод только Finance API (POST, camelCase, числа строками, токен «Финансы»).
- WB присылает не `Retry-After`, а **`X-Ratelimit-Retry`** (секунды). Свой клиент выброшен,
  взят `lib/wbClient.js` из ветки `claude/losses-wildberries-p8dhw6`.
- `period: 'weekly'` на коротком свежем окне отдаёт обрезанную неделю с нулями по логистике и
  штрафам. Для свежих окон только `daily`.
- Суммы в отчётах — **KGS**, не рубли: всегда читать поле `currency`.
- Для расследований сохранять **сырой** ответ WB: нормализация теряет поля
  (`warehouseLogisticsCoeff`, `bonusTypeName` у логистики).
- `deliveryAmount = 1` не означает доставку покупателю — у возвратных строк тоже единица.
- `\w` в регулярках не матчит кириллицу без `/u` — в каталоге нужен `[а-яё]`.
- В каталоге важен порядок: «Сторно…» и «Компенсация…» должны идти раньше похожих штрафов.
- Медиана базовой линии в копейках даёт «всплеск в 2 000 000×» — база должна быть не меньше
  1% текущей суммы.
- Пустая выгрузка не равна «всё в порядке»: при сбое сбора сторож обязан сказать именно это.
- Дефекты печатной вёрстки видны только на рендере: инлайн-`<span>` игнорирует `width`,
  `.banner b { display:block }` рвёт абзацы, нулевые столбцы рисуют «обрубок».
- `pdftoppm` не установлен — PDF постранично не посмотреть; проверял скриншотами HTML через
  `/opt/pw-browsers/chromium --screenshot`, для нижних разделов вырезал секции во временный файл.

## Открытые вопросы (нужно решение пользователя)
Все заморожены до возвращения пользователя после переезда на VPS.

1. **Перенос на виртуальный сервер — ЖДУ ОТВЕТА.** Пользователь переносит наработки с
   Mac Mini на VPS. Для сторожа это меняет только способ запуска: вместо LaunchAgent
   нужен systemd-таймер или cron (`0 7,18 * * *` по времени сервера, в `WATCH.md`
   команда уже есть). Установщик `scripts/mac-mini-install.sh` под Linux не поставит
   агент, остальное отработает. Рекомендация: при возврате сделать
   `deploy/wb-finewatch.service` + `.timer` по образцу plist.
2. **Установлен ли сторож на Mac Mini — НЕИЗВЕСТНО.** Пользователь не помнит. Проверка:
   `launchctl list | grep finewatch` и `tail ~/wb-headless/logs/wb-watch.log`. Если да —
   перед переездом выключить: `launchctl bootout gui/$UID/com.wbheadless.finewatch`,
   иначе после настройки VPS сообщения пойдут дважды.
3. **PR в main — ЖДУ ОТВЕТА.** Ветка готова (девять коммитов). Решено не открывать.
4. **Пороги сторожа** (`config/watch-thresholds.json`): штраф от 500, доля удержаний
   45%, всплеск ×3. Подтвердить после первой недели реальной работы — её пока не было.
5. **Судьба зависшего хвоста** (1 334 возврата ≈ 311 тыс сом, выдачи 21/24/25.08): на
   05.09 проверить не успели — сбор данных прервали по просьбе пользователя. Первым
   делом при возврате: свежий прогон и сверка, оплатили ли эти выдачи.
6. **Очередь возвратов в Казани** (459 шт на 31.08) и **11 просроченных в Бишкеке** —
   разбор по артикулам и складам ФФ не начинали.
