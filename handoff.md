## Что изменилось
Задача трижды переопределялась по ходу, каждый раз — существенно:

1. **Старт:** разбор присланного .docx «Инструкция для проекта "Склад поставщика"». Вывод: это
   чек-лист регистрации, а не инструкция по работе; нет экономики, договора, требований к
   помещению, регламента обработки возврата.
2. **Правка №1 — «система не ХБС, а FBS».** Перестроил рамку: проект встраивается в FBS
   («Маркетплейс»), где в «Поставки и заказы → Настройки» селлер выбирает, куда идут возвраты —
   на склад WB или в свой пункт.
3. **Правка №2 — аудио-вводная.** Выяснилось главное: это **ППЗ**, формат для крупных селлеров с
   крупногабаритом (холодильники, стиралки) с отгрузкой со своего склада; сейчас идёт **пилот** по
   расширению на остальных; кабинет пользователя — тестовый. Это объяснило все нестыковки
   инструкции (активация «без замка», вывеска «любым значением», отсутствие оферты).
4. **Финал:** аналитика переписана целиком под ППЗ, с 23 слайдов ужата до 12 по просьбе пользователя.

Ключевая находка, ради которой стоило переделывать, — **считаемый механизм выгоды**. С 18.06.2026
WB даёт скидку **−1,5% с комиссии** при передаче заказа в течение 13 часов (раньше −1%); 13–18 ч
нейтрально; после 18 ч — повышающие коэффициенты 0,30/0,35/0,45. Свой ППЗ на складе = вы всегда в
первом окне. Отсюда порог окупаемости: при наёмном приёмщике (~60 тыс./мес) нужен оборот FBS
**от 4 млн ₽/мес**, при совмещении с существующим персоналом (~15 тыс./мес) — **~1,2 млн ₽/мес**.
Вход 50–110 тыс. ₽ против 450–900 тыс. ₽ у классического ПВЗ.

## Что пробовали и НЕ сработало

**1. `pandoc` для чтения .docx — не установлен.** Обошёл: распаковка zip + разбор
`word/document.xml` через `xml.etree` на Python (обход дерева с обработкой `w:p` и `w:tbl`).
Работает надёжно, скриншоты вытащил из `word/media/`.

**2. `ffmpeg` из Playwright (`/opt/pw-browsers/ffmpeg-1011/ffmpeg-linux`) не читает Ogg Opus** —
падает с «Invalid data found when processing input», хотя `file` уверенно определяет формат как
валидный Ogg/Opus. Это урезанная сборка без нужного демуксера. **Обошёл:** `pip install
imageio-ffmpeg` даёт полноценный статический ffmpeg 7.0.2. Не тратить время на отладку
playwright-сборки — сразу ставить imageio-ffmpeg.

**3. `pdftoppm`/`pdftocairo`/`gs`/`convert` — ничего из этого в контейнере нет.** Проверка
свёрстанных PDF глазами без растеризатора невозможна. **Обошёл:** `pip install pymupdf`, затем
`page.get_pixmap(dpi=72).save(...)` → чтение PNG. Это обязательный шаг, а не опциональный: из
23 слайдов первой версии два имели обрезанный текст, увидеть это можно было только на растре.

**4. Растеризация выборочных страниц по списку индексов — источник ошибки.** Написал
`for i in [1,3,4,...]: save(f'pg{i+1}.png')`, из-за чего часть файлов осталась от прошлого прогона,
и я решил, что правка таблицы штрафов не применилась (а она применилась). **Вывод:** после каждой
пересборки растеризовать **все** страницы целиком, не выборочно.

**5. Ручная нумерация слайдов в HTML разъезжается при вставке нового слайда в середину.** Первая
попытка чинить `sed`-ом дала последовательность 10, 11, 12, 12, 13, 14. **Обошёл:** нумерация
проставляется на этапе сборки регуляркой `re.sub(r'class="num"[^>]*>\s*\d*\s*</div>', ...)` со
счётчиком — исходники держат пустой `<div class="num"></div>`.

**6. Шрифты: в контейнере из кириллических только DejaVu Sans / Liberation / FreeSans.** Никаких
Inter/Roboto. Внешние шрифты не подгружаются. Верстать сразу под `'DejaVu Sans', sans-serif`.

**7. Первая версия отчёта была построена на экономике классического ПВЗ** (процент от оборота
выдачи, кризис рынка ПВЗ, отзывы владельцев) — и оказалась к задаче почти нерелевантной, потому что
у ППЗ нет выдачи покупателям и, соответственно, этой выручки. **Урок:** при разборе незнакомой
аббревиатуры сначала добиться однозначного определения термина, потом строить модель. Две трети
работы первой итерации ушло в мусор.

**8. Публичных данных по ППЗ как партнёрскому формату в интернете фактически нет** — поисковая
выдача упорно подменяет его на ПВЗ. Рабочая опора: сторона FBS (правила сдачи поставок, кС,
автоотмена, хранение возвратов) + оферта ПВЗ как ориентир по стилю отношений WB с партнёром.

**9. `cd` в составной bash-команде сбрасывает рабочую директорию** между вызовами (в логе видно
«Shell cwd was reset»), из-за чего `git` в той же цепочке падал с «not a git repository».
Держать git-команды отдельным вызовом из корня репозитория.
