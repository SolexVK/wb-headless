Ветка: `claude/production-plan-twv8ki`. Деплой — на Mac mini владельца (openclaw@Mac-mini-Vital),
путь `/Users/openclaw/wb-headless`, порт 8477, за Tailscale (`https://mac-mini-vital.tail13d29e.ts.net:8444`).
Пользователь работает с **ноутбука через Tailscale**, не на самом Mac mini.

## Цель
SPA для планирования пошива одежды. Финмодель показала кассовый разрыв → пользователь сокращает план
по цветам/объёмам. Чтобы не потерять текущий план, сделали **физическую замороженную копию сервиса**
(отдельная папка + отдельная БД + отдельный launchd-сервис), и настроили **две версии рядом**,
переключаемые с ноутбука по вкладкам. Правки объёмов идут в рабочей, оригинал заморожен.

## Что пробовали и НЕ сработало (грабли — важно)
- **`cp -R` папки «на живую» небезопасен** — БД в WAL. Правильно: `sqlite3 ".backup"` (консистентно) +
  `cp -Rc` (APFS-клон) для остального; проверка `PRAGMA integrity_check` → ok.
- **Cookie сессии привязан к ХОСТУ, не к порту** — рабочая и архив на одном ts.net-хосте, поэтому с
  Telegram-входом на обоих логин на одном разлогинивал бы другой. → архив держим БЕЗ входа
  (`TELEGRAM_BOT_TOKEN=` пусто), он приватен внутри tailnet.
- **launchd = урезанный PATH** → в plist полный PATH + абсолютный node; путь к `claude` также в
  `planner/data/.env` (`CLAUDE_CLI_PATH`).
- **Telegram-виджет привязан к домену, не к порту** — на localhost не грузится; на ts.net-хосте
  работает на любом порту (HTTPS от Tailscale).
- **Метку сперва правили прямо в HTML архива** — заменили на переменную; если в старом архиве HTML
  правился руками, перед `git pull` — `git checkout -- planner/public/index.html`.
- Грабли прошлых сессий (актуальны): подписка Claude только через `claude` CLI; Mac mini без прокси
  без интернета; прокси socks5+auth → мостик `proxy-chain` `:8118`; свой launchd планировщика
  `com.wbheadless.planner` (homebrew node, `--experimental-sqlite`).

## Команды для проверки
Синтаксис (в контейнере):
```
cd planner && npm install
node --check server.js && node --check lib/nlq.js && node --check lib/currency.js && node --check public/reports.js && node --check public/app.js
```
Проверка подписи (без БД): поднять `PLANNER_INSTANCE_LABEL="АРХИВ · Тест" PLANNER_PORT=8096 node server.js`,
`curl -s localhost:8096/ | grep -o '<title>[^<]*</title>'` → должен содержать метку; без переменной —
обычный заголовок и 0 плашек «📦».

На Mac mini (обе копии на одном билде):
```

curl -s http://localhost:8478/api/health   # архив   → тот же билд
launchctl list | grep -E 'wbheadless|vital'  # planner, archive, proxybridge — числовые PID
```

рабочая (`:8444`) без метки, архив (`:8445`) с «АРХИВ · Версия 1»; умные запросы и курс обменников
