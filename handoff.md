## Что пробовали и НЕ сработало (грабли)
- **Внутренние снимки как решение для «заморозить план» — пользователь отказался.** Боится, что при
  переключении/восстановлении данные (сезонность, Гант, отчёты) рассинхронизируются и восстановление
  будет долгим. Вывод на будущее: для «заморозить весь сервис» — предлагать ФИЗИЧЕСКУЮ копию папки,
  а не in-app версии.
- **Копировать папку «на живую» просто `cp -R` НЕЛЬЗЯ безопасно:** БД в режиме WAL, копия может
  попасть на середину записи → рассинхрон db/-wal/-shm. Решение: базу копировать через
  `sqlite3 planner.db ".backup '<цель>'"` (консистентный онлайн-снимок, без остановки сервиса),
  остальное — обычным `cp`. Для скорости/диска — `cp -Rc` (APFS clonefile), с откатом на `cp -R`.
- Грабли прошлых сессий (актуальны): подписка Claude работает ТОЛЬКО через `claude` CLI (не через
  Messages API); Mac mini без прокси не имеет интернета (npmjs/claude.com таймаут, github/nbkr.kg — ок);
  прокси у пользователя socks5+auth → Chrome/undici его не умеют → подняли мостик `proxy-chain`
  `http://127.0.0.1:8118`→socks5 (launchd `com.vital.proxybridge`, `~/proxy-bridge/bridge.js`);
  под launchd PATH урезан → путь к claude прописан в `planner/data/.env` (`CLAUDE_CLI_PATH`);
  у планировщика свой launchd `com.wbheadless.planner` (homebrew node, `--experimental-sqlite`).

## Команды для проверки
Синтаксис (в контейнере):
```
cd planner && npm install
node --check server.js && node --check lib/nlq.js && node --check lib/currency.js && node --check public/reports.js && node --check public/app.js
```
Курс (вживую): `node -e 'import("./lib/currency.js").then(m=>m.fetchRates()).then(r=>console.log(r.source,r.usdKgs,r.rubKgs))'`
→ source «Обменники Бишкека … продажа», usdKgs ~87–88.

Архивация на Mac mini (рецепт, который выдан пользователю; base — `$HOME/wb-headless`):
```
ARCH="$HOME/wb-headless-ARHIV-$(date +%Y-%m-%d)"
cp -Rc "$HOME/wb-headless" "$ARCH" 2>/dev/null || cp -R "$HOME/wb-headless" "$ARCH"
sqlite3 "$HOME/wb-headless/planner/data/planner.db" ".backup '$ARCH/planner/data/planner.db'"   # если есть sqlite3
rm -f "$ARCH/planner/data/planner.db-wal" "$ARCH/planner/data/planner.db-shm"
sqlite3 "$ARCH/planner/data/planner.db" "PRAGMA integrity_check;"   # ждём ok
```
Открыть архив потом: `cd "$ARCH/planner" && PLANNER_PORT=8478 node server.js` → http://localhost:8478.
