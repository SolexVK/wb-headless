## Цель
Финмодель показала кассовый разрыв. Задача: **сократить план продаж с ~311k до ~200k шт (Эпоха 1)**,
убирая в первую очередь **слабо продающиеся расцветки** (по фактическим ВЫКУПАМ за 6 мес из кабинета
ВБ), затем — количествами. Если 200k мало — Эпоха 2 под финмодель (пользователь даст позже).
Строим фичу «✂️ Сокращение плана» поэтапно. Решения пользователя: метрика = выкупы шт; цель Эп.1 ~200k;
применять сразу, НО с откатом; «убрать расцветку» = обнулить в матрице + перевести цвет в архив
(archivedColors) → пересчёт Ганта/ткани/финансов.

## Что пробовали и НЕ сработало (грабли)
- **Штуки=0 / покрытие 0%:** читал план из `article.matrix`, а он после миграции в партии пуст.
  Фикс: считать из `state.partias[].planMatrix`, МАКС по этапам.
- **Цвет не появлялся в сшивке (напр. «морская волна»):** «Ключ WB» = список конкретных nmID, резолвер
  брал ровно их. Фикс: `expandByImt` — по любому nmID подтягиваем всю цветовую семью по imtID.
- **Вход на 8444 сломался (битый виджет Telegram):** НЕ из-за наших правок (login.html не трогали до
  code-login). Причина: виджет грузится браузером с `telegram.org`, а он в регионе блокируется; сессия
  истекла (TTL 30 дней) → выкинуло на вход. Обход: (а) войти с VPN на ноуте (виджет нужен только в
  момент входа), (б) СДЕЛАНО — резервный вход по коду (PLANNER_LOGIN_CODE), не зависит от Telegram.
- **Cookie сессии привязан к ХОСТУ, не к порту** (актуально для двух инстансов на одном ts.net-хосте):
  архив держим БЕЗ входа, чтобы не разлогинивать рабочий.
- Прошлые грабли (в силе): подписка Claude только через `claude` CLI; Mac mini без прокси нет
  интернета; мостик `proxy-chain` :8118→socks5(США); launchd урезает PATH (CLAUDE_CLI_PATH в .env);
  БД в WAL — архив копировать через `sqlite3 .backup`.
