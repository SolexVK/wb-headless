# Handoff — WB-инструменты (ветка `claude/mpstats-token-env-1s3duh`)

Дата хендоффа: 2026-07-05. Репозиторий: `solexvk/wb-headless`.

## 1. Цель

Строить полезные инструменты для работы с Wildberries на базе **энциклопедии**, собранной из
видео-уроков. Текущий фокус — **инструмент конкурентного анализа**, который по нише (и, опционально,
своему артикулу) выдаёт многоблочный отчёт и **план доработки карточки**: деньги (топ-конкуренты),
**маржинальный ценовой коридор** (юнит-экономика от себестоимости), принадлежность (цвета), контент-
бенчмарк, конкуренты по ключевым запросам и готовые данные по топам (смыслы/слайды/характеристики).
Экспорт в HTML и **кликабельный PDF**.

## 2. Текущее состояние

Всё закоммичено и запушено в ветку `claude/mpstats-token-env-1s3duh`. Готово:

Отчёт состоит из блоков: **A** ёмкость/сезонность · **B** ТОП-N конкурентов · **B2** конкуренты по

**Проверка без сети:** `python3 .claude/skills/wb-competitor-analysis/wb_analyze.py --selftest
[--html-out f.html] [--pdf-out f.pdf]` — собирает весь отчёт на синтетике.

**Пример боевого запуска (когда будет квота MPStats):**
```
python3 .claude/skills/wb-competitor-analysis/wb_analyze.py \
  --gender women --item рубашка --pattern полоска \
  --my-sku <артикул> --cost <себестоимость> \

  --top 10 --days 30 --html-out /tmp/wb.html --pdf-out /tmp/wb.pdf --json-out /tmp/wb.json
```

## 4. Что изменилось (ключевые коммиты последней части)

- **Юнит-экономика** — ядро (`unit_calc`, `price_buyer_for_margin`, `price_segments`,
  `compute_economics`, `ECON_DEFAULTS`); блок C переделан из «привлекательной цены по выручке» в
  **маржинальный коридор + сегменты × маржа/прибыль + вердикт**. Фундамент под будущий UNIT-калькулятор.
- **HTML-отчёт** (`build_html`, `--html-out`) — дашборд, тёмная/светлая тема, интерактивный чек-лист
  (localStorage). **PDF** (`--pdf-out`) через headless Chromium — ссылки кликабельны.
- **Фаза 3** — блок D: реальные цвета по SKU выбранных ТОП-игроков (склейки), взвешенно по выручке,
  8 цветов + «у скольких топов».
- **Фаза 2** — слой публичных API WB (`wb_search`, `wb_basket_card`, `wb_slide_urls`,
  `wb_characteristics`) с ретраями/кэшем; **не тратит квоту MPStats**.
- **Фаза 4** — `--keywords`: блок B2, конкуренты из выдачи WB, метка 🆕 для отсутствующих в ТОП категории.
- **Фаза 5** — блок F2: смыслы (теги хвостов запросов), слайды листинга топов (миниатюры в HTML/PDF),
  сравнительная таблица характеристик топов с доминантой (`enrich_cards`, `tail_words`, `char_matrix`).

### Подтверждённые параметры юнит-экономики (дефолты, общие для всех товаров)
Себестоимость — **спрашивать каждый раз** (`--cost`, в среднем ~536 ₽, landed до склада WB).
Комиссия ВБ до СПП **35,7%** · СПП **4%** · эквайринг **4,7%** · налог **2%** (от цены с СПП) ·
ДРР запуск/выход **30%/8%** · брак **2,5%** (от себестоимости) · выкуп **36%** (только для оценки
объёма) · логистика/хранение **0** · целевая маржа **25–30%**.
Модель: маржа от цены **без СПП** `S = P/(1−СПП)`; комиссия — от `S`; эквайринг/налог/ДРР — от цены
с СПП `P` (как в MPStats); брак — от себестоимости; маржа % = операц. прибыль / `S`.
Проверка на C=536: безубыток ≈ 1051 ₽, коридor 25–30% ≈ **2094–2613 ₽** на витрине (сходится вручную).

## 5. Что пробовали и не сработало (грабли)

- **MPStats дневная квота (429)** — на 04–05.07.2026 исчерпана; **полный боевой прогон не сделан**.
  Движок распознаёт конверт `{code,message}` и выводит понятную ошибку (не «нет данных»). Ждём сброса.
- **Дата контейнера 2026-07-05 опережает горизонт данных MPStats** → запросы за «будущие» даты
  приходят пустыми (`{data:[],total:0}`) — это не ошибка API. Для теста брать прошлые периоды.
- **WB search** отдаёт `products` в **корне** JSON (не под `data`) — было 0 результатов, **исправлено**
  (`d.get("data",{}).get("products") or d.get("products")`). Обязательны `curl --compressed` + `User-Agent`.
- **WB basket CDN (характеристики/слайды)** тоже **429 при пачках** запросов — добавлены ретраи на
  правильный хост + задержка 0.4 c между карточками + кэш; обогащение **best-effort** (в моей сессии
  из-за многих тестов грузилось 1/4–2/5; на одиночном реальном прогоне полнее). Деградирует мягко.
- **`card.wb.ru/cards/v2/detail`** периодически 0/404 — **не используем**; характеристики берём из
  `basket .../info/ru/card.json` (там полный `options`) — работает надёжно.
- **basket-хост по vol** — таблица `BASKET_RANGES` покрывает vol до ~5189 (basket-27) + фолбэк на
  соседние хосты. Для очень новых артикулов (бол́ьшие vol) может понадобиться расширить таблицу.
- **Chromium print-to-pdf** — работает (`--headless --no-sandbox --print-to-pdf`), ссылки кликабельны;
  предупреждение dbus безвредно. Бинарь ищется по `CHROMIUM_BIN` → `/opt/pw-browsers/chromium` → PATH.
- **Инструменты харнеса `Artifact` и `AskUserQuestion`** дважды падали с «permission stream closed» —
  демо отдавали через `SendUserFile`, вопросы задавали текстом.
- **Конверсии в корзину/заказ по запросу** — только **ДЖЕМ** (у пользователя есть подписка), нельзя
  дёрнуть программно. Пока — помеченная задача в плане; нужен импорт выгрузки ДЖЕМ.

Формальных unit-тестов в репо нет; работоспособность проверяется так:

```
# self-test движка конкурентного анализа (без сети, на синтетике) — собирает весь отчёт
python3 .claude/skills/wb-competitor-analysis/wb_analyze.py --selftest

python3 .claude/skills/wb-competitor-analysis/wb_analyze.py --selftest --html-out /tmp/r.html --pdf-out /tmp/r.pdf
# синтаксис
python3 -m py_compile .claude/skills/wb-competitor-analysis/wb_analyze.py
node --check server.js && node --check report-stock.js
# публичные API WB (без квоты MPStats): быстрый живой тест выдачи
python3 -c "import sys;sys.path.insert(0,'.claude/skills/wb-competitor-analysis');import wb_analyze as W;print(len(W.wb_search('рубашка',5)))"
```

**Ожидаемое состояние (на момент записи):** `--selftest` завершается строкой `[selftest] OK`;
`py_compile` и оба `node --check` проходят; ветка **сливается с `origin/main` чисто** (конфликты
`.gitignore`/`package.json`/`server.js` разрешены объединением). Единственное «красное» —
**полный боевой прогон MPStats блокируется квотой 429** (ожидаемо, не поломка; ждёт сброса квоты).
`wb_search` вживую иногда отдаёт меньше карточек из-за 429 WB — норма, деградирует мягко.
