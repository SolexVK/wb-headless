## Что пробовали и НЕ сработало
- **WebFetch по ряду страниц отдаёт HTTP 403 Forbidden.** Не открылись:
  `weirdwealth.io/ai-influencer-income/`, `nextdiffusion.ai/.../fluxgym-on-runpod`,
  `stable-diffusion-art.com/skin-detailer/`. Обход: брал нужные факты и цифры из сниппетов
  WebSearch (они достаточно детальные) + из тех страниц, что фетчатся. Для weirdwealth первая
  попытка WebFetch как раз прошла и дала разбивку доходов — но повторно та же и соседние страницы
  начали отдавать 403. Вывод: не полагаться на WebFetch конкретной страницы, дублировать
  несколькими WebSearch-запросами.
- **MCP github периодически отваливается и переподключается** (в контексте прилетали системные
  сообщения connect/disconnect). На работу не влияло — GitHub-инструменты не использовались,
  всё делалось через git CLI. Если понадобятся PR/issue — сначала прогреть через ToolSearch.
