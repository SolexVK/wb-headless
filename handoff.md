# Handoff — планировщик производства (planner/)

Ветка: `claude/production-plan-twv8ki`. Деплой — на Mac mini владельца (openclaw@Mac-mini-Vital),
порт 8477, за Tailscale (`https://mac-mini-vital.tail13d29e.ts.net:8444`).

## Цель
SPA для планирования пошива одежды. В этой сессии: (1) командная строка на естественном языке для
отчётов по ткани («опиши отчёт словами» → фильтр), работающая ПО ПОДПИСКЕ Claude через прокси;
(2) курсы валют по обменникам вместо официального.

## Текущее состояние
Всё внедрено, задеплоено на Mac mini, у пользователя работает. Последний билд:
`currency-exchange-office-2026-08-28` (APP_BUILD == BACKEND_BUILD).

Работает:
- Умные запросы к отчётам «Ткань помесячно» (r2a) и «Закупка ткани» (r2b): фраза → JSON-фильтр.
- Режим ПОДПИСКИ: сервер вызывает локальный `claude -p` (headless) через мостик-прокси. Без оплаты
  за токены. Токен подписки (1 год, `claude setup-token`) и прокси хранятся в БД, задаются формой
  «🤖 Нейросеть → ⚙ Настройки подключения».
- Предпросмотр «🧠 Как система поняла запрос» (фильтр + пояснение до применения), кэш фраз
  (повтор мгновенно), исключения (кроме/без/исключить).
- Курсы: обменники Бишкека (valuta.kg, продажа), откат на НБ КР.
- Автозапуск через launchd (мостик + планировщик) — переживает перезагрузку (проверено ребутом).

## Файлы, над которыми работали
- `planner/lib/nlq.js` — НОВЫЙ. Разбор фразы→фильтр: режим API (ключ) и режим CLI (`claude -p`,
  подписка) с автовыбором; прокси+токен в дочерний процесс; healthCheck; классификация сбоя
  (proxy/auth); кэш фраз (LRU 300); схема фильтра включая `exclude`.
- `planner/lib/currency.js` — переписан: основной источник valuta.kg (курс продажи), fallback НБ КР.
- `planner/server.js` — эндпоинты `/api/reports/nlq-status|nl-query|nlq-test`,
  `/api/settings/anthropic`, `/api/settings/nlq` (прокси/токен/ключ); загрузка прокси/токена из БД;
  probeCli() при старте.
- `planner/public/reports.js` — командная строка, панель настроек нейросети, чипы, предпросмотр,
  исключения; в buildReportsData — фильтры source/season/text + exclude.
- `planner/public/app.js` — только APP_BUILD.

## Что изменилось
- Нейросеть = ТОЛЬКО переводчик «фраза → JSON-фильтр из закрытого списка». Отчёт всегда строит
  детерминированный код (buildReportsData). ИИ не исполняет код, не видит данные кроме справочников.
- Подписка вместо API-ключа: `claude -p --output-format json --append-system-prompt`. Приоритет:
  есть ANTHROPIC_API_KEY → режим 'api'; иначе найден `claude` → 'cli'; иначе текстовый поиск.
- Язык фильтров расширен: include (planshet/article/month/source/season/text) + exclude (то же +
  text[] по подстроке). Дорожная карта: этап2 (числовые сравнения) и этап3 (произвольная логика) —
  НЕ сделаны, по запросу.
- Курс: `rates/sell/usd/87-80` → 87.80 с valuta.kg.

## Что пробовали и НЕ сработало (грабли — важно)
- **Официальный API под подписку НЕ существует.** Messages API = отдельный платный продукт (ключ).
  Подписка работает ТОЛЬКО через Claude Code (`claude` CLI). Решение: сервер шелит `claude -p`.
- **Claude Code НЕ был установлен на Mac mini.** Токен берётся ТОЛЬКО из `claude setup-token`
  (нужна установленная и залогиненная программа). Поставили через npm (`@anthropic-ai/claude-code`).
- **У Mac mini нет интернета без прокси** (npmjs, claude.com — таймаут; github/nbkr.kg работают).
  Ставили и логинились с `HTTPS_PROXY` в окружении.
- **Прокси у пользователя — socks5 с авторизацией** (`socks5://…@200.10.39.195:8000`, выход в США).
  Проблемы: (а) Chrome в принципе НЕ умеет socks5 с логином/паролем; (б) undici/Node fetch НЕ умеет
  socks5; (в) claude мог не понять socks5. Решение — **локальный мостик**: `proxy-chain` поднимает
  `http://127.0.0.1:8118` → апстрим socks5. Через мостик ходят и Chrome, и claude, и (если понадобится)
  Node. Мостик оформлен в launchd (`com.vital.proxybridge`, `~/proxy-bridge/bridge.js`, env UPSTREAM).
- **claude.com блокировал по региону** — потому что БРАУЗЕР шёл мимо прокси (реальная страна).
  «Браузером по умолчанию» проксированный Chrome сделать нельзя (тот же бинарь). Решение: не полагаться
  на авто-открытие — скопировать URL авторизации из терминала и вставить в Chrome, запущенный с
  `--proxy-server=http://127.0.0.1:8118 --user-data-dir=…`; код вернуть в терминал.
- **launchd-дубликат планировщика конфликтовал по порту.** У пользователя УЖЕ есть launchd-сервис
  `com.wbheadless.planner` (homebrew node, `--experimental-sqlite`). Наш `com.vital.planner` падал с
  EADDRINUSE. Решение: удалили наш дубликат, оставили `com.wbheadless.planner`; путь к claude жёстко
  прописали в `planner/data/.env` (`CLAUDE_CLI_PATH=…/.nvm/…/bin/claude`), т.к. под launchd PATH урезан.
- **`pkill -f 'proxy-bridge/bridge.js'` не совпадал** — argv процесса просто `bridge.js`. Killали по PID.

## Команды для проверки
Синтаксис (в контейнере):
```
cd planner && npm install   # зависимости не закоммичены; ставить в свежем клоне
node --check server.js && node --check lib/nlq.js && node --check lib/currency.js && node --check public/reports.js && node --check public/app.js
```
Курс (вживую): `node -e 'import("./lib/currency.js").then(m=>m.fetchRates()).then(r=>console.log(r))'`
→ ожидаем source «Обменники Бишкека … продажа», usdKgs ~87–88.

На Mac mini (деплой):
```
cd ~/wb-headless && git pull origin claude/production-plan-twv8ki
lsof -nP -iTCP:8477 -sTCP:LISTEN -t | xargs kill 2>/dev/null   # com.wbheadless.planner поднимет заново
sleep 3 && curl -s http://localhost:8477/api/health
launchctl list | grep -E 'vital|wbheadless.planner'            # оба с числовыми PID
curl -x http://127.0.0.1:8118 -s https://api.ipify.org         # 200.10.39.195 = мостик жив
```
**Ожидаемое зелёное сейчас:** `node --check` всех файлов — OK; на Mac mini health отдаёт
`currency-exchange-office-2026-08-28`; умный запрос («муслин в китае», «исключить марлёвку и муслин»)
разбирается за ~10с первый раз и мгновенно при повторе; курс в шапке — обменник (продажа).
Формальных unit-тестов в проекте нет; проверка — `node --check` + ручной прогон.
