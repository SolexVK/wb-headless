# Справочник товара

Файлы этой папки **не хранятся в git** — репозиторий публичный, а себестоимость и цены
это коммерческая тайна. Всё восстанавливается командами ниже за секунды.

| Файл | Что внутри | Чем восстановить |
| --- | --- | --- |
| `cost.json` | себестоимость производства по nmID | `node scripts/import-cost.mjs <файл.xlsx>` |
| `prices.json` | цены со скидкой продавца из кабинета | `node scripts/wb-prices.mjs` |
| `barcodes.json` | карточки и баркоды до размера | `node scripts/wb-barcodes.mjs` |

Требуется в окружении: `Wildberries_API` (или `WB_CONTENT_TOKEN`), `MPSTATS_TOKEN`.

Исходный xlsx с себестоимостью держите **вне репозитория** — путь передавайте аргументом.

## Порядок восстановления с нуля

```bash
node scripts/wb-barcodes.mjs                    # состав ассортимента до размера
node scripts/wb-prices.mjs                      # цены со скидкой продавца
node scripts/import-cost.mjs ~/себестоимость.xlsx
```

## Что означают уровни

- **Модель** — фасон: РЖП, РМК-твид. Живёт в `config/groups.json`.
- **nmID** — модель × цвет, одна карточка WB. Живёт в `config/skus.json`.
- **Баркод** — nmID × размер, торгуемая единица. Только в `barcodes.json`.

Себестоимость и цена задаются на уровне **nmID**: размеры внутри карточки считаются
равными по себестоимости. Если цены размеров в кабинете различаются, `wb-prices.mjs`
берёт медиану и помечает карточку как `mixed`.

## Почему цену нельзя брать из MPStats

MPStats отдаёт **витринную** цену — уже со скидкой постоянного покупателя. Наша
юнит-экономика считается от **цены со скидкой продавца, без СПП**. На сверке 21 SKU
линейки РЖП расхождение составило в среднем **24,6 %**: MPStats показывал 1 763–2 000 ₽
там, где в кабинете стояло 2 299–2 420 ₽.

Расчёт по цене MPStats занижает маржу примерно вдвое: по той же линейке получалось
7,8 % вместо фактических 18,9 %. Поэтому база маржи — всегда `prices.json`.
