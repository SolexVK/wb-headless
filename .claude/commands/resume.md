Возобновить работу из handoff-файла. Аргумент — необязательный slug: $ARGUMENTS

Определи, какой handoff читать:
1. Если аргумент не пустой — файл `handoffs/<slug>.md`.
2. Если пустой — выведи slug из имени текущей git-ветки
   (`git branch --show-current`) и попробуй `handoffs/<slug>.md`.
3. Если файл не найден — покажи список всех файлов в `handoffs/` (с датой и
   строкой «Цель» из каждого) и СПРОСИ, какой брать. Не угадывай.

Когда файл выбран:
1. Прочитай его целиком.
2. Прогони команды из «Команды для проверки» и сверь с ожидаемым состоянием.
   Если реальность разошлась с ожиданием — сообщи прежде чем продолжать.
3. Если есть «Открытые вопросы» для решения пользователя — задай их ПРЕЖДЕ
   чем писать код.
4. Иначе — приступай к «Следующий шаг».

Кратко перескажи, где мы остановились, прежде чем действовать.
