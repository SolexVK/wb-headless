name: resume
description: Возобновить работу из handoff-файла — прочитать состояние задачи, проверить, что сборка рабочая, и продолжить с следующего шага. Поддерживает несколько параллельных задач через slug.
---

Аргумент (необязательный) передан в `$ARGUMENTS` — это slug (короткое имя задачи).

Определи, какой handoff читать:
1. Если `$ARGUMENTS` не пустой — файл `handoffs/<slug>.md`.
2. Если пустой — выведи slug из имени текущей git-ветки
   (`git branch --show-current`) и попробуй `handoffs/<slug>.md`.
3. Если нужный файл не найден — покажи список всех файлов в `handoffs/`
   (с датой обновления и строкой «Цель» из каждого) и СПРОСИ пользователя,
   какой брать. Не угадывай.

Когда файл выбран:
1. Прочитай его ЦЕЛИКОМ.
2. Прогони команды из раздела «Команды для проверки» и сверь результат
   с ожидаемым состоянием, описанным в файле. Если реальность разошлась
   с ожиданием — сообщи об этом пользователю прежде чем продолжать.
3. Если в файле есть «Открытые вопросы», требующие решения пользователя —
   задай их ПРЕЖДЕ чем писать код.
4. Иначе — приступай к разделу «Следующий шаг».

Кратко перескажи пользователю, где мы остановились, прежде чем действовать.
