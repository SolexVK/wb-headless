# Флаги `season-plan.js`

## Источник группы / предмет
- `--path "<путь предмета>"` — предмет WB (напр. `Женщинам/Блузки и рубашки/Рубашка`).
- `--group <ЛИНЕЙКА>` — своя линейка из `config/groups.json`. С `--path` включает
  бленд 90/10 (форма от аналогов, уровень от своих). Без `--path` — per-SKU (дорого).
- `--label "<текст>"` — метка отчёта (иначе берётся из path/group).

## Фильтр аналогов
- `--words a,b` — оставить, если имя содержит ЛЮБОЕ (стем-словоформы).
- `--all-words a,b` — доп. слова-признаки; **мягкий** сигнал релевантности (не
  отсекают), ранжируют отбор.
- `--exclude a,b` — выкинуть, если имя содержит любое (стем).
- `--brands a,b` / `--exclude-brands a,b` — по брендам.
- `--price-min N` / `--price-max N` — ценовой коридор, ₽.
- `--min-sales N` — минимум продаж **в месяц**.
- `--min-revenue N` — минимум выручки **в месяц**, ₽ (проходит по ИЛИ с продажами).
- `--limit N` — сколько топ-аналогов в группу (обычно 60).
- `--max-pages N` — предохранитель пагинации (по умолчанию 8 × 1000 строк).

## Период
- `--from YYYY-MM-DD --to YYYY-MM-DD` — **прогнозный** (будущий) период. Задан →
  режим прогноза.
- `--d1 YYYY-MM-DD --d2 YYYY-MM-DD` — окно истории. По умолчанию последние 2 года.

## Уровень / параметры плана
- `--base-source own|market|target` — источник уровня. `own` требует `--group`.
- `--target-units N` — цель по штукам на период (для `target`).
- `--ambition K` — коэффициент роста (× к базе).
- `--competitor-weight 0.9` — доля конкурентов в бленде (Правило 3).
- `--recency-weight 2` — вес недавнего года (Правило 2).
- `--min-price N` — пол цены по unit-экономике.
- `--hot-coeff`, `--rating-lead`, `--logi-lead` — пороги/лаги фаз.

## Улучшения
- `--oos` — поправка на out-of-stock (восстановление спроса в дни простоя внутри
  активного окна карточки).
- `--weekly` — недельный профиль (коэффициенты по дням недели).

## Интерактив
- `--interactive` — задать все параметры в диалоге. Без `--group`/`--path` диалог
  включается автоматически.

## Пример (прогноз, рекомендуемый набор)
```bash
node season-plan.js --path "Женщинам/Блузки и рубашки/Рубашка" \
  --words "клетка" --all-words "демисезон,оверсайз" \
  --exclude "полоска,лето,джинс" --price-min 1800 --price-max 3900 \
  --min-sales 80 --min-revenue 100000 --limit 60 \
  --from 2026-08-01 --to 2027-03-31 --oos --weekly
```
