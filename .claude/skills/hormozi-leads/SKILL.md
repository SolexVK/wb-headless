# Hormozi Leads — привлечение (Core Four)

Помогаешь получать **engaged leads** (тех, кто *проявил интерес* — истинный выход рекламы), а не просто контакты. Реклама = игра «входы → выходы».

> Язык: RU-инструкции, EN-термины. Глубокий референс — `hormozi/books/03-100m-leads.md`.
> Есть эталонный скилл-первоисточник: github.com/getagentseal/founder-playbook/100m-leads.

## Lead Magnet — как заставить лида проявить интерес

**Core Offer напрямую** — пробуй сначала (прямой путь к деньгам). Для дорогого/холодного — сначала **Lead Magnet**: полное решение *узкой* проблемы, обнажающее следующую (её решает core offer). «Give away the secrets, sell the implementation.» Лид-магнит должен быть Grand Slam Offer'ом (см. `hormozi-offers`).

**7 шагов:**
1. Узкая проблема + core offer решает следующую.
2. Тип: **Reveal Problem** (диагностика) / **Sample-Trial** / **One Step of Multi-Step**.
3. Доставка: **Software / Information / Service / Physical** (3 типа × 4 = 12 вариантов).
4. Название — **тестируй** (headline → image → subheadline). Заголовок = «80 центов доллара».
5. Легко потреблять (все форматы) → ×2-4 take rate.
6. Реально хорош (репутацию строит free; 99% не купят, но оценят).
7. **CTA** = *что делать* (ясно: «call now») + *причина сейчас*.

**CTA — причины действовать сейчас:** Scarcity (кол-во, честная) · Urgency (время) · **Fraternity Party Planner** (придумай reason why — любая причина > никакой). «Don't be clever, be clear.»

## THE CORE FOUR — единственные 4 способа рекламы

Аудитория (Warm/Cold) × Коммуникация (1-to-1/1-to-many):

|  | Warm | Cold |
|---|---|---|
| **1-to-1** | **Warm Outreach** | **Cold Outreach** |
| **1-to-many** | **Content** | **Paid Ads** |

Не хватает лидов → делаешь Core Four недостаточно *умело* или *много*. Старт: warm outreach → дальше, если времени > денег → content; если денег > времени → cold/ads.

1. **Warm Outreach** (1-to-1, warm) — первые 5 клиентов. Проси не «купи», а «знаешь кого-то?». **A-C-A**: Acknowledge → Compliment → Ask. Give-Give-Give-Ask.
2. **Content** (1-to-many, warm) — **Hook → Retain → Reward**; «give until they ask».
3. **Cold Outreach** (1-to-1, cold) — **Personalization + Big Fast Value + Volume** (+ автоматизация). Дальше A-C-A. Бенчмарк: CAC < ⅓ LTGP.
4. **Paid Ads** (1-to-many, cold) — Callouts + **What-Who-When** + CTA; цель — Client-Financed Acquisition (см. `hormozi-finance` / `hormozi-money-models`).

## MORE · BETTER · NEW — масштабирование Core Four

- **MORE — Rule of 100:** 100 primary actions/день, 100 дней подряд (100 контактов, или 100 минут контента/рекламы). Диагностика: «Что мешает делать ×10 от текущего?»
- **BETTER:** только через **тестирование**. Найди **constraint** (шаг с макс. отвалом — там макс. ROI). 1 тест/нед/платформа, логируй, бей текущий «best».
- **NEW** (когда возврат от more/better падает): **new placement → new platform → new Core Four activity**. Помни **Size of the Pie Fallacy** — рынок в разы больше, чем кажется.

## Lead Getters — масштаб через других (Section IV)

Не «действия», а люди, делающие Core Four за тебя:
1. **Customer Referrals** — дешевле/качественнее всего. **Referral Growth Equation:** рефералы vs отток (referrals > churn → рост без рекламы). Не получают, т.к. (а) продукт хуже, чем кажется, (б) не просят. Цель — ≥25% из рефералов.
2. **Employees** — масштабируют без тебя (управление временем — см. Maker/Manager в `hormozi/books/04`).
3. **Agencies** — приводят лиды и *учат навыкам*.
4. **Affiliates** — рассказывают своей аудитории; активируй через **launches**.

## Open to Goal + One-Page Plan

- **Rule of 100** = обязательство на *действия*. **Open to Goal** = на *результаты* (5 продаж/день — сколько бы ни заняло). «Right action in the wrong amount still fails.»
- **One-Page Advertising Plan (5 шагов):** (1) тип лида: Customers/Affiliates/Employees/Agencies → (2) Rule of 100 или Open to Goal → (3) расписать ежедневное действие → (4) делать до найма → (5) сделать целью employees, повторить.
- **Roadmap 7 уровней:** warm outreach → +content → +employees → +referrals(≥25%) → +new places/team → +killers(execs) → $1B+.
