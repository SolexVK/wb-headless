# Типы удержаний Wildberries: признаки, причины, меры

Машинная версия этого справочника — `lib/deductionCatalog.js` (там же regex для
распознавания). Здесь — человеческие пояснения к каждому типу.

## Где что искать в строке детализации

| Колонка | Что означает |
|---|---|
| `penalty` | штраф |
| `deliveryService` | логистика (прямая или возвратная — смотри `bonusTypeName`) |
| `paidStorage` | платное хранение на складе WB |
| `paidAcceptance` | платная приёмка поставки |
| `deduction` | прочие удержания (реклама, перевыставленные издержки, подписки) |
| `additionalPayment` | доплата **в пользу продавца** (компенсации) |
| `bonusTypeName` | **причина** — главное поле расследования |
| `sellerOperName` | вид операции: Продажа / Возврат / Штраф / Логистика / Удержание |

Комиссия площадки отдельной колонкой не приходит: она равна
`retailAmount − forPay` по строкам продаж и возвратов (с учётом знака возврата).

## Штрафы

| Причина (`bonusTypeName`) | Что это | Первое действие |
|---|---|---|
| Штраф МП. Невыполненный заказ (отмена продавцом) | Заказ принят, но не собран и не отгружен. ≈28% цены товара | Найти склад и дату постановки заданий: сбои кучные |
| Платное хранение возвратов на ПВЗ более 3 дней | Возврат лежит на пункте выдачи, посуточная плата | Организовать вывоз, назначить ответственного по ПВЗ |
| Выявленные расхождения в карточке товара после приемки | Факт не совпал с карточкой (состав, размер, комплектность) | Исправить карточку; штраф оспорим с фото и спецификацией |
| Удержание за занижение габаритов упаковки | Замер склада больше заявленного | Перемерить упакованный товар, обновить карточку |
| Подмена товара / неверное вложение | В отправлении не тот товар | Поднять видео сборки, разобрать со складом ФФ |
| Самовыкупы (антифрод) | Антифрод счёл заказы накруткой | Сверить с реальными заказами, при ложном срабатывании — возражение |
| Маркировка товара | Проблемы с КИЗ | Перевыпустить коды, вводить в оборот до отгрузки |
| Нарушение сроков поставки | Слот сорван или недовоз | Переносить слот заранее — дешевле штрафа |

## Логистика: причина определяет смысл

| `bonusTypeName` | Смысл |
|---|---|
| Возврат товара, который приехал по МП, продавцу (К продавцу) | Невыкуп или возврат покупателя — везут обратно продавцу |
| Возврат брака (К продавцу) | Брак отправлен продавцу |
| Возврат товара продавцу по отзыву (К продавцу) | Возврат по претензии |
| Возврат неопознанного товара (К продавцу) | Склад не идентифицировал товар |
| *(пусто, при операции «Логистика»)* | **Прямая доставка покупателю.** При действующих ИУ на логистику продаж таких строк быть не должно — это повод для обращения в поддержку |

Тариф перевозки = базовая ставка + литраж × объём, умноженные на
**коэффициент склада** (`warehouseLogisticsCoeff`, встречались 1,0–2,0).
Один и тот же товар через «дорогой» склад стоит в полтора-два раза дороже.

## Прочие удержания

| Причина | Смысл | Реакция |
|---|---|---|
| Оказание услуг «WB Продвижение», документ №… | Реклама | Сверить с рекламным кабинетом и ДРР |
| Возмещение издержек по перевозке | Перевыставленные транспортные расходы | Сверить с фактическими перемещениями |
| Подписки, сервисы WB | Регулярное списание | Проверить, окупается ли |
| **Сторно. …** | Отмена ранее удержанного — деньги вернулись | Зафиксировать, какой аргумент сработал |
| Компенсация подменённого/потерянного товара | Выплата **продавцу** | Сверить сумму с себестоимостью |

Строки «Сторно…» и «Компенсация…» распознаются **раньше** похожих штрафов:
«Сторно. Расхождения в карточке» — это возврат денег, а не новый штраф.

## Что считать проблемой

- Любой штраф выше порога (`config/watch-thresholds.json`, по умолчанию 500).
- Всплеск: сумма по причине выше медианы обычного дня в 3 раза и более.
- **Незнакомая причина** — всегда: каталог не полон, а молчать нельзя.
- Прямая логистика при действующих ИУ.
- Возвраты, которые ждут забора дольше бесплатного окна (≈2 суток), и особенно
  возвраты со статусом «Истек срок хранения на пвз» — там теряется сам товар.
- Доля всех удержаний вместе с комиссией выше ориентира (по умолчанию 45% выручки).

Не считать проблемой: рекламу, подписки, сторно и компенсации — это фон,
он идёт в сводку. Но всплеск по ним тоже поднимает тревогу.
