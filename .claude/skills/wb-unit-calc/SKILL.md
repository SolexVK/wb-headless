# /wb-unit-calc — Юнит-калькулятор товара на WB

Считает экономику товара на единицу по **подтверждённой пользователем модели**
(то же ядро, что в блоке C конкурентного анализа `[3]`). Логика —
`lib/wbUnitCalc.js`, CLI — `scripts/wb-unit-calc.mjs`, `npm run unit:calc`.

## Модель (не менять без запроса пользователя)

Две цены на карточку:
- `S` — цена **продавца без СПП** (база маржи и комиссии).
- `P` — цена **покупателя с СПП** (витрина, как в MPStats). `P = S·(1−СПП)`.

| Статья | База | Ставка по умолчанию |
|---|---|---|
| Комиссия ВБ (до СПП) | `S` | 35,7% |
| Эквайринг | `P` (с СПП) | 4,7% |
| Налог | `P` (с СПП) | 2% |
| ДРР (запуск / выход) | `P` (с СПП) | 30% / 8% |
| Брак | себестоимость `C` | 2,5% |
| Логистика + хранение | ₽/ед | 0 (индивидуальные условия) |
| Себестоимость `C` | — | **спрашивать каждый раз** |

```
Прибыль = S − 0,357·S − (0,047+0,02+ДРР)·P − 0,025·C − C − (логистика+хранение)
Маржа % = Прибыль / S
Цена под маржу m:  S = [C·(1+брак)+fixed] / (k − m),  k = 1 − ком − (эквайр+налог+ДРР)·(1−СПП)
```

**Выкуп 36%** — НЕ статья затрат (логистика 0). Только для оценки объёма.
Первоисточник модели — `.claude/skills/wb-competitor-analysis/references/analysis-workflow.md`.

## Обязательный порядок

1. **Спроси себестоимость `C`** — её всегда даёт пользователь, дефолта нет.
2. **Цена** (одно из): `--price` (витрина с СПП), `--seller-price` (без СПП) или
   `--nm` (подтянуть витринную цену по артикулу из MPStats, нужен `MPSTATS_TOKEN`).
   Без цены калькулятор всё равно выдаёт коридор и безубыточность.
3. Если нужно — цели обратного расчёта (`--target-margin`, `--target-profit`) и
   объём (`--units`) для прогноза заработка.

## Запуск

```bash
# базовый расчёт по цене и себестоимости
npm run unit:calc -- --cost 536 --price 2400

# полный: обратный расчёт под маржу 28% + прогноз на 300 ед + HTML-отчёт
npm run unit:calc -- --cost 536 --price 2400 --target-margin 28 --units 300 --html

# цена по артикулу из MPStats
MPSTATS_TOKEN=xxx npm run unit:calc -- --cost 536 --nm 167477208

# только себестоимость → коридор цены под целевую маржу и безубыточность
npm run unit:calc -- --cost 536

# PDF-отчёт (нужен playwright/Chromium; npm install на свежем контейнере)
npm run unit:calc -- --cost 536 --price 2400 --pdf
```

## Флаги

- `--cost N` — себестоимость `C`, ₽ (**обязателен**).
- `--price N` — витринная цена `P` (с СПП). `--seller-price N` — цена продавца `S`.
- `--nm <nmId>` [`--period 30`] — подтянуть витринную цену по артикулу (MPStats).
- Ставки в **процентах**: `--commission 35.7 --spp 4 --acquiring 4.7 --tax 2
  --drr 8 --drr-launch 30 --defect 2.5 --m-min 25 --m-max 30`.
- `--logistics N --storage N` — ₽/ед, если условия не индивидуальные.
- `--target-margin M` / `--target-profit X` — обратный расчёт цены.
- `--units N` — прогноз заработка за период.
- Вывод: по умолчанию текст; `--json`; `--html [path]`; `--pdf [path]`
  (без пути — авто-имя `reports-output/unit-calc_<цена>x<C>_<дата>.<ext>`).

## Что выдаёт

1. **Раскладка на единицу** — все статьи в ₽ → опер. прибыль, маржа %, рентабельность к `C`.
2. **Ценовой коридор** под целевую маржу + маржа в фазе запуска + **точка безубыточности** (рабочая и в запуске).
3. **Обратный расчёт** — витринная цена под заданную маржу или прибыль/ед.
4. **Чувствительность** — таблицы «цена → прибыль/маржа» и «ДРР → прибыль/маржа».
5. **Прогноз за период** (при `--units`).

## Проверка

```bash
node --check lib/wbUnitCalc.js scripts/wb-unit-calc.mjs
npm run unit:calc -- --cost 536 --price 2400        # эталон: прибыль 705 ₽, маржа 28%,
                                                     # коридор 2094–2613 ₽, безубыточность 1051 ₽
```
