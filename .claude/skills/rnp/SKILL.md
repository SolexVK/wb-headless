# РНП — рука на пульсе

Период: `$ARGUMENTS` (если не задан — вчерашний день, сравнение с предыдущими 7 днями).

Это оркестрация в основной сессии. Субагенты не могут вызывать других агентов, поэтому
последовательность держит эта сессия, а агенты вызываются отсюда.

Цель — **две минуты чтения**. Не отчёт, а список того, что требует решения сегодня,
с уже предложенным решением по каждому пункту. Если решать нечего — так и написать одной
строкой. Пустая РНП лучше, чем РНП ради формы.

## Шаг 1. Данные

Проверить свежесть источников:

- `data/sales/`, `data/ads/`, `data/reviews/` — есть ли выгрузка за период
- `data/stock/ff-stock-*.csv` — свежесть остатков по фулфилментам
- `reports-output/stock-*.json` — прогон `report-stock.js`, если сегодня ещё не было

Чего не хватает — назвать сразу и продолжать с тем, что есть, пометив пробелы.
Не откладывать всю сводку из-за одного файла.

## Шаг 2. Агенты параллельно

Запустить одним сообщением:

- `review-triage` — новые отзывы: категории, системные дефекты, что чинить
- `ads-analyst` — окупаемость кампаний по марже, ДРР от выкупленной выручки
- `unit-economics` — маржа по артикулам, где сменилась цена или выкуп

Топ-10 артикулов дают 80–90 % выручки — разбирать в первую очередь их.

## Шаг 3. Механические проверки

Их делает сама сессия, агенты для этого не нужны:

1. **Выпавшие размеры** — баркоды с нулевым остатком при ненулевых заказах за 7 дней.
2. **Дней до нуля** — остаток / скорость заказов, отдельно по каждому фулфилменту.
   Меньше срока подсорта — красный флаг.
3. **Цена вне коридора** — сравнить с коридором из `unit-economics`.
4. **Маржа ниже порога** — ниже 10 % по `config/economics.json`.
5. **Реклама против остатка** — кампания разгоняет то, чего осталось меньше,
   чем на срок поставки.
6. **Рейтинг** — падение ниже 4,5 по любому артикулу топ-10.

## Шаг 4. Сводка

```
# РНП <дата>

## Состояние
Заказов <n> (<±%> к среднему за 7 дней). Выручка <сумма>. Выкуп <%>.
Артикулов в топ-10 с проблемами: <n>.

## Требует решения сегодня
| Что | Артикул | Цифра | Что предлагаю | Цена вопроса |
Не больше пяти пунктов, по убыванию денег. Каждый — с готовым решением,
а не с формулировкой «обратить внимание».

## Под наблюдением
<то, что близко к порогу, но решения пока не требует>

## Данных не хватило
<какие источники не обновлены>
```

## Шаг 5.

Одной строкой: что требует решения человека прямо сейчас.

Ничего не отправлять наружу: ни изменения цены, ни ставок, ни ответов покупателям.
Готовые формулировки — да, отправку — нет.
