# /wb-top-keywords — ТОП по ключевой фразе (MPStats)

Инструмент **[1]** каскада. По ключевой фразе берёт ВСЮ поисковую выдачу WB из
MPStats за период, прогоняет через двухуровневую фильтрацию и отдаёт список
конкурентов (контракт `top-rivals`) + при желании HTML-отчёт с фото и цветом.
Логика — `lib/wbTopKeywords.js`, CLI — `scripts/wb-top-keywords.mjs`
(`npm run top:keywords`). Транспорт (эндпоинт + пагинация) — `lib/mpstats.js`.

Доступ: `MPSTATS_TOKEN` в окружении (заголовок `X-Mpstats-TOKEN`).
**Эндпоинт залочен:** `POST https://mpstats.io/api/analytics/v1/wb/search/items`
(ключевое слово — query-параметр `path`; период `d1`/`d2`, d2 строго раньше сегодня;
тело ag-grid `{startRow,endRow}`). **Потолок выдачи — ~100 товаров на фразу**
(эндпоинт не отдаёт больше; топ-500 через него недостижим).

## Обязательный порядок: предполётный диалог

Перед запуском СОБЕРИ параметры у пользователя (по одному вопросу или списком),
покажи итоговый набор на подтверждение — и только потом запускай:

1. **Ключевая фраза** (обязательно).
2. **Период** — пресет `7/30/90` дней или точные `d1`/`d2` (YYYY-MM-DD).
3. **Размер топа** (10/100/500…) — режется ПОСЛЕДНИМ шагом (помни про потолок 100).
4. **Группы-признаки** (крой/воротник/манжеты…) — формат `имя = стем1, стем2`,
   **стемами без окончаний** (`прям`, `приталенн`, `стойк`) — матчинг подстрокой,
   морфология ловится сама. Группы соединяются **ИЛИ** (метки, не жёсткий гейт).
5. **Слова-исключения** (`exclude`) — жёсткий гейт: противоположные значения и
   «не наши» категории (`притал, стойк, без ворот, волан, парео`).
6. **Ценовой коридор** по средней цене продажи (`price-min`/`price-max`).
7. **Опц.:** порог отсева выручки (дефолт 100 000₽), `exception-rank` (дефолт ТОП-20),
   `min-rating`/`min-reviews`/`min-sales`, наш артикул (`--our`, исключить), фото (да/нет).

## Логика фильтрации (что именно происходит)

1. Тянем всю выдачу за период (пагинация) → отсев выручки `< revenueFloor`.
2. По названию: **exclude — жёсткий гейт** (любое слово → вон); **группы — ИЛИ**
   (матч хотя бы по одной = проходит как `group`). «Безхвостый» генерик (ни одного
   ключа групп) остаётся, если выручка ≥ ТОП-`exceptionRank` пула — **порог считаем
   по пулу БЕЗ exclude-хитов** (исключённые не задают планку).
3. Метрические фильтры (коридор по средней цене продажи, опц. рейтинг/отзывы/продажи).
4. Сортировка по выручке (убыв.) → отсечка топ-N последним шагом.

`avgSalePrice` = средняя цена продажи (`final_price_average` = revenue/sales).
`lostProfit` — доп. показатель (не фильтруем). `matchType`: `group`/`exception`/`all`.

## Запуск

```bash
# Полный прогон + HTML-отчёт (имя файла авто = «<фраза>_<дата>.html», с фото и цветом)
npm run top:keywords -- --query "рубашка в полоску женская" --period 90 --top 100 \
  --group "крой=оверс,прям" --group "воротник=отлож" \
  --exclude "притал,стойк,волан" --price-min 1900 --html

# JSON-контракт в файл (авто-имя, если без пути) или в stdout
npm run top:keywords -- --query "платье женское" --period 30 --out
npm run top:keywords -- --query "платье женское" --top 20

# Таблица-пикер в терминал (шаг РУЧНОГО выбора конкурентов для [2])
npm run top:keywords -- --query "рубашка в полоску женская" --period 90 --top 20 \
  --group "крой=оверс,прям" --exclude "притал,стойк" --price-min 1500 --pick

# Авто-топ-K БЕЗ выбора (если явно нужен): голый массив nmId в пайп → [2]
npm run top:keywords -- --query "платье" --top 4 --nmids-only | \
  node scripts/wb-cards-compare.mjs --our 167477208
```

Флаги: `--period N` | `--d1/--d2` · `--top N` · `--group "имя=стем,стем"` (повторяемый)
· `--exclude "a,b"` · `--price-min/--price-max` · `--revenue-floor` · `--exception-rank`
· `--min-rating/--min-reviews/--min-sales` · `--our nmId` · `--out [путь]` ·
`--html [путь]` (без пути → авто-имя с фразой и датой) · `--no-images` · `--pick` ·
`--max-rows`.

## Связка [1]→[2] — РУЧНОЙ выбор конкурентов (по умолчанию)

Стык с «Сравнением карточек» [2] — **осознанный шаг человека**, не авто-труба.
Порядок:

1. Прогони [1] с `--pick` (и/или `--html`). `--pick` печатает нумерованную таблицу
   `# · nmId · бренд · название · ср.цена · выручка · тип` в stdout; номер строки
   совпадает с HTML-отчётом.
2. **Покажи таблицу пользователю** и попроси назвать 2–4 конкурента — номерами строк
   (`1,4,7`) или прямо nmId. Не выбирай сам (можно предложить кандидатов по выручке,
   но финальное слово — за пользователем).
3. **Спроси НАШ артикул** (`--our`) — его всегда даёт пользователь, никогда не подставляй.
4. Запусти [2] c выбранными: `node scripts/wb-cards-compare.mjs --our <НАШ> --rivals <nmId,…>`
   (сперва DRY-RUN, после подтверждения — `--submit`; всего в сравнении ≤5 карточек).

Авто-топ-K (`--nmids-only | …`) оставлен как запасной путь для явных запросов
«просто возьми топ-N» — по умолчанию используем ручной выбор через `--pick`.

**HTML-отчёт** самодостаточен: фото вшиты в data-URI (доп. запросов к MPStats нет,
только миниатюры с CDN WB), артикулы кликабельны, «безхвостые» помечены бейджем.
Имя файла = ключевая фраза + дата выдачи (легко искать позже).

## Интеграция в каскад (программно)

Логика — функция, её зовёт оркестратор `scripts/wb-pipeline.mjs` напрямую:

```js
import { topByKeywords, formatHtml, embedThumbnails } from './lib/wbTopKeywords.js';
const res = await topByKeywords({
  query: 'рубашка в полоску женская', d1, d2, topN: 100, our,
  filters: { deep: { groups: [{key:'крой',any:['оверс','прям']}], exclude: ['притал','парео'] },
             priceMin: 1900, revenueFloor: 100000 },
});
const rivals = res.rivals.map(r => r.nmId);          // → в «Сравнение карточек» [2]
// await embedThumbnails(res.rivals); const html = formatHtml(res);  // отчёт
```

Контракт `top-rivals` и полная схема фильтров — в `docs/pipeline/README.md`.

## Если нет токена / пустой результат

- Нет `MPSTATS_TOKEN` — попроси добавить в переменные окружения среды (то же место,
  где `Wildberries_API`); подхватится в новой сессии.
- Пусто после фильтров — ослабь фильтры (ниже `revenue-floor`, шире коридор цены,
  меньше слов в `exclude`, выше `exception-rank`) или проверь стемы в группах.
- Проверка синтаксиса ключей: они матчатся ПОДСТРОКОЙ — `прямой` не поймает
  «прямого», нужен стем `прям`.
