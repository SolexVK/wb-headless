# /wb-brand-market-share — доля бренда от рынка по фразе (MPStats)

По паре **БРЕНД + поисковая фраза** собирает отчёт о доле бренда в нише этой
фразы за **30 и 90 дней**. «Весь рынок» = вся поисковая выдача Wildberries по
фразе за период (данные MPStats, метод «Товары по поисковой фразе»).

Логика и рендер — `scripts/brand-share.mjs` (`npm run report:brand-share`).
Транспорт (эндпоинт + пагинация) — `lib/mpstats.js`. Один отчёт = один файл
на пару бренд+фраза (HTML и PDF), сразу за оба периода.

Доступ: `MPSTATS_TOKEN` в окружении (заголовок `X-Mpstats-TOKEN`). Для PDF нужен
Chromium (Playwright) — на свежем контейнере сперва `npm install`.

## Что внутри каждого отчёта

Порядок блоков (сперва весь блок за 30 дней, затем жирный разрыв — период
90 дней с новой страницы в PDF — и тот же блок за 90 дней):

1. **Общая информация по бренду** — доля рынка в штуках и в выручке, продажи (шт),
   выручка, число карточек бренда в выдаче, средняя цена продажи, ранг бренда среди
   всех брендов ниши (по штукам и по выручке), итог по нише.
2. **ТОП рынка по фразе** — ТОП-10 карточек выдачи; **строки бренда подсвечены**;
   сортировка **по выручке**.
3. **Артикулы бренда с наибольшими продажами** — до 15 карточек бренда, сортировка
   **по выручке**, колонка «Доля рынка (выручка)».

## Обязательный порядок: предполётный диалог

Перед запуском собери у пользователя (одним списком) и покажи на подтверждение:

1. **Бренд** — как он пишется в выдаче WB (матч подстрокой, регистр не важен:
   `AIZEK` поймает `Aizek`).
2. **Поисковая фраза(ы)** — одна или несколько (по фразе = один отчёт).
   Если фразы неизвестны — сперва подбери их (см. «Смежные инструменты»).
3. Периоды фиксированы (30 и 90 дней, d2 = вчера) — менять не нужно, если не просят.

## Запуск

```bash
# Одна пара бренд+фраза → HTML + PDF в reports-output/
npm run report:brand-share -- --target "AIDEMIKO|Рубашка муслиновая женская"

# Несколько отчётов за один прогон (--target повторяемый), свой каталог вывода
npm run report:brand-share -- --out reports-output \
  --target "AIDEMIKO|Рубашка из муслина женская" \
  --target "AIDEMIKO|Рубашка муслиновая удлиненная" \
  --target "AIZEK|Муслиновая рубашка мужская"

# Без --target — дефолтная демо-пара (AIDEMIKO/AIZEK) для проверки
npm run report:brand-share
```

**Флаги:** `--target "БРЕНД|фраза"` (повторяемый; бренд и фраза через `|`) ·
`--out <каталог>` (по умолчанию `reports-output`).

**Выход:** `reports-output/brand-share-<бренд>-<фраза>.{html,pdf}` (кириллица в
имени транслитерируется). В stdout — короткая сводка по каждому отчёту (доля,
продажи, выручка, ранг) для быстрого пересказа в чате.

## Метод и оговорки (обязательно проговорить пользователю)

- **«Весь рынок» = вся выдача WB по фразе.** MPStats отдаёт **до ~100 карточек**
  на фразу (это потолок метода — топ-500 недостижим). Значит «доля» и «ранг» —
  внутри этой выдачи, а «число карточек бренда» — сколько карточек бренда попало
  в выдачу, а не весь ассортимент бренда.
- **Доля** = сумма по карточкам бренда ÷ сумма по всей выдаче, отдельно **в штуках**
  и **в выручке**. Ранг бренда — по агрегату продаж/выручки среди всех брендов ниши.
- **Данные MPStats оценочные** (восстановлены по остаткам/выкупам) — для сравнения
  и ранжирования, не бухгалтерия из кабинета. Для ФАКТИЧЕСКИХ выкупов — скилл
  `wb-brand-keyword-sales`.
- `pageSize` при запросе к MPStats = 100 (больше эндпоинт не отдаёт: `endRow > ~100`
  роняет его 500-й). Менять не нужно.

## Смежные инструменты (тот же движок MPStats)

- **Подбор фраз** — `node scripts/phrase-probe.mjs`: прогоняет список фраз-кандидатов
  и показывает ёмкость каждой ниши (выручка/мес, продажи, карточки) + попадание
  брендов. Использовать, когда фразы для отчёта ещё не выбраны. Список кандидатов —
  в начале файла (константа `CANDIDATES`), правится под задачу.
- **Короткий ТОП-20 брендов** — `node scripts/brand-top20.mjs`: компактная таблица
  ТОП-20 брендов ниши по фразе за месяц (выручка, доля, продажи, число артикулов),
  целевой бренд подсвечен. Один короткий HTML+PDF на все фразы.
- **ТОП конкурентов по фразе** — скилл `wb-top-keywords` (инструмент [1] каскада).

## Если нет токена / пустой результат

- Нет `MPSTATS_TOKEN` — попроси добавить в переменные окружения среды (там же, где
  `Wildberries_API`); подхватится в новой сессии.
- PDF не собирается / нет Chromium — выполни `npm install` (ставит Playwright);
  движок сам подставит бинарь из `/opt/pw-browsers`.
- Пустая выдача по фразе — проверь формулировку (иногда синонимы дают разную выдачу)
  и что дата d2 = вчера (эндпоинт не принимает сегодняшнюю дату).
