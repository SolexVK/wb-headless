# Производственный план (planner)

Инструмент планирования отшива рубашек: план продаж → этапы → распределение по
цехам → диаграмма Ганта → дашборд с вехами, тканью и логистикой до WB.

## Запуск

```bash
npm install
npm run planner        # http://localhost:8090  (PLANNER_PORT — переопределить порт)
```

Открой в браузере, данные сохраняются в `planner/data/state.json` (в git не коммитится).

## Что делает

- **Данные** — ручной ввод: артикулы (цвета, размерный ряд, расход ткани м/шт,
  план по этапам в штуках), цеха (роль основной/вспомогательный, мощности
  крой/пошив/утюжка/ОТК в шт/день), этапы (месяцы продаж, календарный месяц
  отшива, дедлайн прихода на WB), параметры (ткань, логистика, пороги потока).
- **Пересчёт (авторасчёт)** — распределяет артикулы по цехам, балансируя время
  завершения (все цеха загружены, сроки держатся). Если объём этапа не влезает
  в один цех за месяц — партия делится между цехами пропорционально мощности
  пошива (основной + вспомогательный). Считает даты операций, заказ ткани
  (лид-тайм 3 недели + буфер), логистику (недельный карго + 10–15 дней),
  подсвечивает срывы дедлайнов и перелив мощности.
- **Диаграмма Ганта** — строки = цеха, блоки = циклы. Внутри блока 4 дорожки
  операций (крой → пошив → утюжка → ОТК) показывают поток с перекрытием.
  Блок можно **тянуть мышью** — сдвигается старт кроя, план мгновенно
  пересчитывается; двойной клик по блоку сбрасывает ручной сдвиг.
- **Дашборд** — KPI, загрузка цехов, готовность артикулов по этапам, таблица
  вех по каждому циклу, сводка заказов ткани.

## Модель производства

- **Этап** = 2 месяца продаж, склеенные, отшивается за 1 календарный месяц.
- **Цикл** = один артикул целиком (все цвета/размеры) одного этапа в одном цехе.
- **Поток внутри цикла**: операции идут с перекрытием (пошив стартует, когда
  скроено ~N шт; утюжка — когда сшито ~N; ОТК — когда отутюжено ~1000). Пошив —
  узкое горлышко и задаёт темп.
- **Без простоя**: следующий крой в цехе стартует по концу пошива предыдущего
  цикла (у операций разные рабочие).
- **Календарь**: 6-дневная неделя (вс — выходной), настраивается.

## Архитектура

```
planner/
  server.js          Express: статика + REST (/api/state, /api/schedule, /api/override)
  lib/
    calendar.js      рабочий календарь (рабочие дни, 6-дневка)
    model.js         схема состояния, значения по умолчанию, сид
    scheduler.js     авторасчёт: распределение, поток, дробление, ткань, логистика
  public/
    index.html, styles.css
    app.js           SPA: вкладки, дашборд, формы, сохранение
    gantt.js         SVG-диаграмма Ганта с перетаскиванием
  data/state.json    состояние (создаётся при первом запуске; не в git)
```

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET  | `/api/state` | текущее состояние |
| PUT  | `/api/state` | сохранить состояние |
| POST | `/api/state/reset` | сбросить к примеру |
| POST | `/api/schedule` | рассчитать расписание |
| POST | `/api/override` | сохранить ручной сдвиг блока и пересчитать |

## Дальнейшие шаги (заложено, но не реализовано полностью)

- Матрица размер×цвет по этапам (сейчас план — суммарно по этапу).
- Мультисезон: несколько планов подряд с бесшовным переходом цехов.
- Буферы под форс-мажоры как отдельные сдвигаемые интервалы.
