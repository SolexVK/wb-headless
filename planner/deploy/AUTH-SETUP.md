# Публичный доступ + Telegram-авторизация

Как открыть планировщик в интернет (Tailscale Funnel) и пускать только
согласованные Telegram-аккаунты. Токены и секреты живут ТОЛЬКО на Mac mini
в `planner/data/.env` (файл gitignored, в репозиторий не попадает).

## 1. Создать Telegram-бота

1. В Telegram напишите **@BotFather** → `/newbot` → задайте имя и username
   (username заканчивается на `bot`, напр. `wbplanner_bot`).
2. BotFather пришлёт **токен** вида `123456789:AA...`. Это секрет.
3. Привяжите домен для кнопки входа: `/setdomain` → выберите бота →
   пришлите ваш Funnel-домен **без https://**, напр.
   `mac-mini.tailXXXX.ts.net`. Без этого шага виджет входа работать не будет.

## 2. Узнать свой Telegram-ID (владелец)

Напишите **@userinfobot** (или @getmyid_bot) — он пришлёт ваш числовой `id`.
Это НЕ секрет. Владелец всегда админ и имеет бессрочный доступ.

## 3. Прописать переменные на Mac mini

Добавьте в `planner/data/.env` (создастся, если нет). Значения — ваши:

```bash
cd ~/путь/к/wb-headless/planner        # каталог с server.js внутри
cat >> data/.env <<'ENV'
TELEGRAM_BOT_TOKEN=123456789:AA_ваш_токен_бота
TELEGRAM_BOT_USERNAME=wbplanner_bot
OWNER_TELEGRAM_ID=55501234
ENV
```

- `SESSION_SECRET` можно не задавать — сгенерируется автоматически и сохранится
  в БД (`meta.session_secret`). Если хотите инвалидировать все сессии — задайте
  свой или удалите ключ из БД.
- Пока `TELEGRAM_BOT_TOKEN` не задан, работает старая защита `PLANNER_PASSWORD`
  (переход без «дыры»). После задания токена Telegram-вход берёт верх.

Перезапустить службу:

```bash
launchctl kickstart -k gui/$(id -u)/com.wbheadless.planner
```

В логах (`out.log`) должно появиться:
`[planner] Telegram-авторизация ВКЛЮЧЕНА (бот @wbplanner_bot, владелец 55501234).`

## 4. Включить Tailscale Funnel (публичный HTTPS)

Требуется один раз включить HTTPS-сертификаты в админке Tailscale
(**DNS → HTTPS Certificates → Enable**) и разрешить Funnel для устройства
(**Machines → Mac mini → Edit ACL / Funnel**, либо в политике `nodeAttrs` добавить
`funnel`).

Затем на Mac mini (порт службы — `PLANNER_PORT`, по умолчанию 8090; в вашей
установке 8477):

```bash
tailscale funnel 8477            # разово
# или постоянно в фоне:
tailscale funnel --bg 8477
tailscale funnel status          # покажет публичный https://…ts.net
```

Публичный адрес будет вида `https://mac-mini.tailXXXX.ts.net`. Он и есть
домен из шага 1.3.

## 5. Выдача доступа другим людям

1. Человек открывает ваш публичный адрес → жмёт «Log in with Telegram».
2. Если его нет в списке — он видит **свой Telegram-ID**. Пусть передаст его вам.
3. Вы (админ) заходите на `/admin` → «Выдать доступ по Telegram-ID» → вписываете
   его ID (по желанию — срок подписки и заметку) → «Выдать доступ».
4. Человек снова жмёт вход — теперь пускает.

Контроль:
- **Заблокировать / разблокировать** — мгновенно рвёт активную сессию.
- **Срок…** — подписка до даты (пусто = бессрочно). После даты доступ закрыт.
- **Удалить** — убирает из списка полностью.
- Одна активная сессия на аккаунт: новый вход вытесняет старую сессию (нельзя
  «поделиться» доступом — второй вход выкидывает первого).

Все данные пользователей — в локальной БД `planner/data/planner.db` (таблица
`users`), в интернет/репозиторий не уходят.
